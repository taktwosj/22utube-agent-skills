# Pre-Script Hook Review

최종 대본을 쓰기 전 반드시 거치는 보조 검토 단계다.

목적은 Gemini JSON을 그대로 대본으로 바꾸는 것이 아니라, 시청자가 첫 3초에 멈출 이유와 하단 첫마디의 방향을 확정하는 것이다.

## 1. 3초 킬러 포인트

첫 3초 안에 보여줄 핵심을 하나 고른다.

후보:

- 결과
- 표정
- 행동
- 물건
- 자막 사고
- 발언
- 반전
- 주변 반응
- 마지막 행동
- 손끝/타격/충돌/슬라이딩 같은 순간

Gemini에서 참고할 필드:

```text
wow_point_candidates_raw
edit_impact_points
visual_focus_timeline
turning_points
remake_notes_for_codex.strongest_visual_moment_ko
```

출력:

```text
3초 킬러 포인트:
- 시간:
- 핵심 화면:
- 멈추는 이유:
- 하단 첫마디에 반영할 요소:
```

## 2. 후킹 유형 4종 후보

최종 대본 전 반드시 4가지 후보를 만든다.

```text
1. 충격형
2. 숫자/시간형
3. 정체 숨김형
4. 리액션형
```

각 후보는 완성 문장이어야 하며, 바로 아래에 `계속 봐야 하는 이유`를 붙인다. 이 이유가 구체적이지 않으면 후보를 다시 쓴다.

좋은 예:

```text
충격형:
문 닫히는 순간, 빌런도 같이 퇴장했습니다
- 계속 봐야 하는 이유: 누가 빌런처럼 보였고 어떤 순간에 퇴장처럼 보였는지 확인하려고 본다.

정체 숨김형:
이 자막 하나 때문에 경기보다 댓글창이 더 터졌습니다
- 계속 봐야 하는 이유: 어떤 자막이 댓글 반응을 터뜨렸는지 확인하려고 본다.

리액션형:
비욘세는 한마디도 안 했는데, 댓글창은 이미 눈빛 해석을 끝냈습니다
- 계속 봐야 하는 이유: 비욘세가 어떤 눈빛을 했고 댓글이 어떻게 해석했는지 보려고 본다.
```

나쁜 예:

```text
비욘세 눈빛이
엘런이 다가오자
이 장면 댓글창이
도대체 무슨 일이 있었을까요?
지금부터 보여드리겠습니다
```

항상 추천안을 하나 고른다.

## 3. 정답/해석/결과 숨김 도발

정답을 바로 말하지 않고 궁금증을 남기는 방식이다.

사용 가능한 표현:

```text
이거
저 장면
마지막 행동
이 사람
이 자막
이 표정
이 한 줄
이 순간
댓글창 반응
```

좋은 예:

```text
이 자막 하나 때문에 경기보다 댓글창이 더 터졌습니다
이 남자, 촬영장에서 쫓겨날 뻔했습니다
마지막 행동 하나 때문에 할머니가 주인공이 됐습니다
```

주의:

- 너무 숨겨서 내용이 불명확해지면 쓰지 않는다.
- 정보형/뉴스/사건/건강/금융은 핵심 주어를 숨기지 않는다.
- 시청자가 첫 3초에 무엇을 봐야 하는지는 반드시 알게 한다.
- 제품 영상이 아닌 11short에서는 `제품명 숨김`보다 `정답/해석/결과 숨김`으로 판단한다.

## 4. 댓글/시청자 반응 교차 확인

댓글이 있으면 댓글 반응이 강한 장면을 우선한다.

댓글이 보는 것:

- 사람들이 진짜 반응한 지점
- 반복해서 언급한 장면
- 밈이 된 표현
- 감동/웃김/통쾌/불편 신호

Gemini가 보는 것:

- 영상 안에 실제로 있는 것
- 시간대별 사건
- 화면 자막
- 표정/행동/음악/대사

둘이 다르면 댓글 쪽을 우선하되, 영상에 근거가 없는 댓글 해석은 쓰지 않는다. 루머, 음모론, 범죄, 성적 조롱, 의료/정신상태 단정, 명예훼손성 댓글은 사실로 쓰지 말고 `시청자 과몰입 반응`으로만 정리한다.

## 5. 오디오오프 이해 보강

원본 음성이 꺼져도 이해되어야 한다.

검토할 필드:

```text
source_audio_mode
viewer_confusion_risks
dialogue_timeline
music_lyric_timeline
onscreen_text_timeline
```

규칙:

- `background_music_only`면 인물 대사를 만들지 않는다.
- `mixed_scene_audio_and_music`이면 실제 대사와 음악 가사를 분리한다.
- `viewer_confusion_risks`가 있으면 하단에서 설명한다.
- 중단은 반응/감정/시각 포인트를 담당한다.
- 하단은 사건의 setup / turn / payoff를 담당한다.

```text
- 충격형:
  - 계속 봐야 하는 이유:
- 숫자/시간형:
  - 계속 봐야 하는 이유:
- 정체 숨김형:
  - 계속 봐야 하는 이유:
- 리액션형:
  - 계속 봐야 하는 이유:
My recommendation:
Reason:

3. 숨김 도발 검토
- 숨길 수 있는 것:
- 드러내야 하는 것:
- 사용 여부:
- 이유:

4. 댓글/반응 교차 확인

- 대본에 반영할 포인트:

- 원본 오디오 상태:

- 하단에서 반드시 설명할 것:

```

그 다음에만 `하단 첫마디 후보 5개`를 제시한다.
