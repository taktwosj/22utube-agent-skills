# Shorts Urakkai Prompt (00-tikitaka / G10 design)

> 외부 우라까이(재해석) 작성용 Prompt. 최초 설계도(분석본)를 기반으로
> 사용자가 외부 AI에게 수동으로 전달한다.

## 목적

```text
최초 설계도(원본 분석본)를 보고
허용 범위 안에서 우라까이(재배열·재작성) 제안을 받는다.
원본 화자 발언·사건 결과는 변조하지 않는다.
```

## 허용

```text
원본 구간 재배열
나레이션 재작성
상황 설명 표현 수정
표현·감정·속도 차별화
쇼츠 구조 profile 변경 제안
```

## 금지

```text
원본 화자 발언 변조
영상에 없는 행동 창작
원본 사건의 결과 변경
```

## 역할 정의

최초 설계도는 창작 완료본이 아니라 원본 분석본이다. 필수 역할:

```text
화자 발언
나레이션 후보
상황 설명 후보
화면 행동
오디오 이벤트
기존 화면 글자
원본 시간
source_order
confidence
```

상황 설명 예시:

```text
(공을 힘껏 걷어찬다)
(말이 그대로 주저앉는다)
(강아지가 언덕 아래로 미끄러진다)
(철컹 소리에 모두 고개를 돌린다)
(겁에 질려 몸을 벌벌 떤다)
(웃음을 참지 못하고 키득거린다)
```

## 상황 설명 취급 규칙

상황 설명은 기본적으로 **visible text** 역할이다. 최종 설계가 명시하지
않는 한 TTS로 자동 변환하지 않는다.

```text
raw transcript marker  ≠  approved situation-description caption
```

## 출력 요청

```text
지정된 빈 칸(나레이션 자리, 상황 설명 자리)만 작성하시오.
원문 화자 발언과 사건 결과를 변경하지 마시오.
영상에 없는 행동을 만들지 마시오.
중복 단어와 AI식 교훈 결론을 피하시오.
추가 근거가 필요하면 NEEDS_EVIDENCE로 표시하시오.
```
