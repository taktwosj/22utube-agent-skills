# Review Rubric

Use this reference when reviewing existing scripts, channel data, or another AI's script.

## Score Categories

Score 0-10 each:

1. **Kept viewer clarity**: does it know exactly who stays?
2. **Discarded viewer clarity**: does it intentionally ignore someone?
3. **Click emotion match**: does the opening match the viewer's pre-click emotion?
4. **Anchor strength**: does one object/number/action remain?
5. **Opening scene**: is there an irreversible moment or broken intuition?
6. **Open loop**: does one main question pull the whole video?
7. **Reward loop**: does each 10-30 seconds pay attention back?
8. **Rhythm**: does it avoid same-length, same-ending narration?
9. **Ending recovery**: does it return to the anchor?
10. **Channel value**: would this make someone subscribe or remember the channel?

Interpretation:

- 90-100: script is strong; stop over-polishing and move to production design unless one specific flaw is blocking the video
- 85-89: strong enough to produce after one focused fix
- 70-84: usable, but fix anchor or ending
- 50-69: generic AI script; rewrite structure
- under 50: park or reframe

## Production Handoff Rule

A script does not need to become 100 inside text.

When a script reaches 90+:

- identify the one remaining textual weakness, if any
- do not keep rewriting the whole script
- move effort to thumbnail, voice, edit rhythm, proof visuals, captions, and first 30 seconds of retention
- treat the next 10 points as production points, not script points

Use this distinction:

```text
Script 90 = ready to produce.
Video 100 = script + voice + thumbnail + edit + proof visuals.
```

If the topic is a comeback, money, debt, investment, or success story, also check:

- does it avoid selling a fake success formula?
- does it explain why the opportunity happened instead of making it feel like luck?
- does the ending give one repeatable action, not vague inspiration?

## Common Failures

### "Good But Forgettable"

Symptoms:

- nice lesson
- many examples
- no single phrase or object remains
- ending says "도움이 되셨다면"

Fix: choose one anchor and rewrite opening/ending around it.

### "School Essay"

Symptoms:

- problem, background, examples, lesson
- no viewer question after the hook
- lists dominate

Fix: turn each section into a question and reward.

### "Choice Hell"

Symptoms:

- too many hook options
- user must choose everything
- no default recommendation

Fix: auto-select one direction and state why.

### "Fake Drama"

Symptoms:

- real incident but invented victim emotions
- unclear reconstruction
- blame before verdict

Fix: label reconstruction and separate fact/inference.

### "AI Mindset Generic"

Symptoms:

- "be confident"
- "just say no"
- "change your mindset"
- warm comfort but no behavior

Fix: begin with defensive thought and give a low-friction sentence or action.
