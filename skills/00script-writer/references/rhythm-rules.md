# Rhythm Rules

Use this when polishing a script, shortening captions, or making another AI's draft sound less generic.

These rules are mechanical on purpose. They help an AI actually change the writing, not merely say "make it more rhythmic."

## Rhythm Pass

Run this after the structure and memory anchor are set.

```text
Rhythm Pass
- Repeated ending risk:
- Ending set chosen:
- Longest sentence:
- Question/fragment placement:
- Single-line punch sentences:
- Mid-script entry risk:
- Caption split risk:
```

## Sentence Rules

- Maximum 3 consecutive sentences with the same ending style.
- After 3 declarative sentences, insert one question, fragment, or one-line reversal.
- One sentence = one idea. Remove double clauses when possible.
- At least one single-sentence paragraph every 30 seconds.
- Keep the anchor sentence short enough to repeat exactly at the ending.
- Replace abstract verbs with visible actions.

## Korean Ending Control

Avoid repeating the same ending too long:

```text
...했습니다.
...했습니다.
...했습니다.
```

Break it with:

```text
그런데 여기서 바뀝니다.
왜요?
이 버튼 하나 때문입니다.
```

## Ending Rhythm Rule

Do not vary endings randomly. Endings should mark the script structure.

Default serious narration set:

```text
Unpack / fact / explanation: ~습니다
Verse / decisive scene / climax: ~다 or noun ending
Transition / open loop: ~까?
```

For history, real incident, comeback story, and serious finance scripts, this three-part set is usually enough. Avoid adding soft chat endings just for variety.

Avoid in serious scripts unless the channel deliberately uses a casual host:

```text
~네요
~죠
~잖아요
```

These can make a heavy scene sound like casual commentary.

Use endings by structure:

```text
[Verse / hook]
그는 이력서에 성공을 쓰지 않았다.
사기당한 이야기를 썼다.
이력서에.
실패를.

[Unpack]
보통 이력서에는 잘한 일을 씁니다.
어디를 다녔는지.
무엇을 해냈는지.

[Transition]
그런데 왜 상준은 실패를 썼을까요?
```

Rules:

- Same ending style should not run 3 times in a row.
- A long `~습니다` explanation should be cut by a short `~다`, noun ending, question, or one-line reversal.
- Climax and memory-anchor lines should be short enough to repeat exactly.
- Ending variety is not the goal. Structural clarity is the goal.

## Ending Sets By Format

Use one ending set per script or channel. Do not mix all styles in one video.

```text
History / serious real story:
~습니다 for unpacking, ~다 or noun ending for verse/climax, ~까? for turns.

Senior / warm mindset:
~습니다, ~거든요, ~잖아요. Use lightly; keep one concrete behavior anchor.

Sassy / revenge shorts:
~다, noun ending, short questions. Casual endings only if the channel brand is openly casual.

Finance / stocks / coin:
~습니다 for safety and explanation, noun endings for numbers, ~까? for check questions.
Never use ending style to sound certain about buying or selling.

CC / observation shorts:
fragments, commands, short questions. The visual remains the main actor.
```

## Verse-Unpack Rhythm

For the user's current script system, use verse to compress and unpacking to explain.

```text
Verse:
one image, one action, one contradiction.

Unpack:
what happened, why it matters, what to watch next.
```

Example:

```text
1미터였다.
차는 똑바로 섰고,
남자는 집으로 올라갔다.

며칠 뒤, 우편물이 왔습니다.
벌금 300만 원.
법은 거리를 보지 않습니다.
시동을 봅니다.
```

## Mid-Script Entry Rule

Use this when a new person, suspect, witness, object, secret, or situation enters
in the middle or late part of a script.

New entries are where scripts usually collapse back into long explanation. Do
not introduce a new person by explaining who they are first. Introduce them with
verse, then unpack.

```text
Mid-Script Entry Pass
- New entry:
- First beat: time, place, or position
- Second beat: visible action or posture
- Third beat: one quoted line or decisive action
- Unpack limit: 1-3 plain sentences after the three beats
- Risk: did the script explain motive/background before showing the entry?
```

### Three-Beat Entry

Every new mid-script entry should start with three short beats:

```text
1. Time / place / position
2. Visible action / posture / object
3. One quoted line / decisive action
```

Then add only a short unpacking paragraph.

Good:

```text
The man who had read the ledger was already there.

He called Park aside, once every few days.

"Leave that column empty."

Heo, the clerk.
The second seat in the government office.
The weakness Park wrote down became Heo's weapon.
```

Bad:

```text
Heo knew from the beginning that poor people could not report the fraud because
the ledger exposed their private weaknesses, so he used Park as the front man
and planned to take over the money later.
```

### Korean Pattern

```text
그 장부를,
처음부터 끝까지 본 사람이 있었다.

그는 멀찍이서,
박씨를 불러냈다.

"그 칸은 비워두게."

허 이방.
관아의 두 번째 자리.

박씨가 적은 약점은,
그의 무기가 됐다.
```

### Hard Rules

- Do not start a new character with "사실 그는..." unless the scene already
  showed the character.
- Do not explain motive, rank, backstory, and plan in the same paragraph as the
  first appearance.
- If the unpack after a new entry is longer than 3 sentences, cut it into a
  verse beat or move the explanation later.
- Witnesses, villains, hidden ledgers, secret letters, sudden memories, and
  official documents all count as new entries.
- Late-script villain explanation should also use this rule. It is the most
  common place where pacing slows down.

## Useful Patterns

```text
Long sentence.
Short sentence.
Question?
One-word or one-object beat.
```

```text
Viewer belief.
Contradiction.
Concrete proof.
New question.
```

```text
Action.
Pause.
Consequence.
Anchor.
```

## Caption Rule

For Shorts, captions should be split as spoken beats, not grammar paragraphs.

Bad:

```text
진짜 경찰인지 헷갈리면 설명하지 말고 끊고 다른 전화기로 확인하세요.
```

Good:

```text
헷갈리면 설명하지 말고
끊고 확인하세요.
```
