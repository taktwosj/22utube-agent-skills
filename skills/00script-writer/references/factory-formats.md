# Factory Formats

Use this reference when the user wants repeatable channel formulas, batch production, or channel-specific scripting.

## General Factory Principle

Do not chase a new genius script every time. Create a repeatable transform:

```text
source material -> viewer emotion -> fixed format -> anchor -> repeatable ending
```

Every channel needs:

- kept viewer
- discarded viewer
- repeated promise
- anchor family
- fixed tone
- reusable ending

## Warren Buffett / Quote Shorts

Purpose: turn authority quotes into relatable failure/comedy plus one investing question.

Formula:

```text
quote
-> my wrong interpretation
-> account/life failure reveal
-> corrected meaning
-> fixed closing
```

Fixed closing candidate:

```text
그리고 제 계좌는요.
```

Example:

```text
버핏은 좋은 회사를 적정한 가격에 사라고 했습니다.
저는 반대로 했습니다.
싼 주식만 골랐고,
제 계좌는 더 싸졌습니다.
```

Use finance safety. Do not recommend buying/selling.

## History / 역사춘

Purpose: make a historical figure or event memorable through one irreversible moment.

Formula:

```text
known judgment
-> one scene that cracks it
-> hidden interest or pressure
-> what changed after that moment
-> one sentence viewers remember
```

Avoid broad "Korean history facts". Narrow each video to one scene or one name.

Anchor examples:

- one royal command
- a blood-stained garment
- one poem line
- one erased name
- one sealed gate

## Sassy / Revenge Shorts

Purpose: create anger, reversal, and comment impulse.

Formula:

```text
unfair scene
-> offender overconfident
-> proof appears
-> public reversal
-> offender pays socially/legally/emotionally
-> comment question
```

Weak: "고개 숙였다" only. Stronger: proof, apology, exposure, restitution, legal consequence, or social loss.

Comment prompts:

- "이 정도면 사과로 끝낼 일인가요?"
- "여러분이라면 여기서 멈춥니까?"
- "이런 사람 본 적 있나요?"

## Mindset / Relationship

Purpose: avoid generic comfort. Start from the viewer's defensive thought.

Formula:

```text
viewer self-hate
-> "you already know the advice but cannot do it"
-> reason beneath behavior
-> lower-friction action
-> one sentence to use
```

Never lead with "just say no", "be confident", or "change your mindset".

Examples:

- 부탁 거절: "오늘 목표는 거절이 아닙니다. 즉답을 멈추는 겁니다."
- 가까운 사람에게 화: "문손잡이를 잡기 전 10초만 멈추세요."

## Scam Prevention

Purpose: turn knowledge into rehearsal.

Formula:

```text
mock call
-> wrong reflex
-> correct sentence
-> family/procedure anchor
-> emergency action
```

Do not list tips first. Put the viewer inside a call.

## Finance / Stocks

Purpose: choose one number or button as the anchor.

Good anchors:

- -30%의 날
- +200% 이후
- 2000억 문턱
- 손익분기선
- 매수 버튼 앞 3초

Formula:

```text
one number
-> why it is strange
-> what changes before/after it
-> what the viewer should check
-> anchor returns
```

Never overload with many metrics.

## Real Failure / Comeback Story

Purpose: turn a personal failure into proof without selling a fake success formula.

Use when the topic is a real comeback, bankruptcy, scam, job loss, debt, failed business, or "10 years later success" story.

Core warning:

```text
Do not sell the result.
Reveal the structure that made the result believable.
```

Formula:

```text
failure contradiction
-> what most people would hide
-> the concrete structure of the failure
-> what the person still did under pressure
-> why someone trusted that evidence
-> repeatable action anchor
```

Strong anchor:

```text
실패를 쓰지 마세요.
실패의 구조를 쓰세요.
```

Structure checklist:

- What happened?
- Who left, betrayed, disappeared, or failed?
- What responsibility remained with the main person?
- What did the person still do instead of escaping?
- What skill or attitude became visible through the failure?
- What should the viewer write or do after watching?

Avoid:

- "10억 버는 법"
- "바닥에서 성공한 비법"
- vague inspiration
- lucky rescuer with no reason
- success-porn thumbnails that make the story feel like a scam funnel

Use a safety line when money or huge success appears:

```text
이 이야기는 10억 아파트 사는 방법이 아닙니다.
그런 영상이었다면, 여기서 이상한 비법을 팔았을 겁니다.
```

Example:

```text
그는 이력서에 성공을 쓰지 않았습니다.
사기당한 이야기를 썼습니다.

대표가 본 건 불운이 아니었습니다.
광고비 100만 원으로 매출 200만 원을 만들던 실력.
그리고 문제가 터졌을 때 도망가지 않았던 태도.

실패는 숨기면 흠이 되고,
구조로 쓰면 증거가 됩니다.
```

## CC / Remake Observation Shorts

Purpose: keep the viewer looking at the source video.

Formula:

```text
point at danger/oddity
-> first object enters
-> second object creates open loop
-> zoom/pause/replay
-> result
-> comment question
```

Caption style:

```text
저 커브 보이세요?
오른쪽 오토바이.
반대편 차가 안 멈춥니다.
잠깐, 뒤에 사람까지 옵니다.
여러분이면 먼저 갑니까?
```

Do not explain history, geography, or context unless it increases tension.
