# Mystery-Sacrifice Template

Use this active template for Korean yadam, sida, revenge, framed-victim,
wrongful-accusation, hidden-villain, and evidence-reversal scripts.

Core emotional lane: `통쾌`

Core flow:

```text
처형/위기 -> 억울 -> 빌런 발견 -> 통쾌
```

This template must still use `references/hook-loop-structure.md`,
`references/intent-anchor.md`, `references/rhythm-rules.md`, and the appropriate
reader/persona gate.

## Eight Rules

1. Start at the crisis.
   - Execution ground, public shame, arrest, forced confession, financial ruin,
     or another irreversible moment.

2. Show why the victim was caught.
   - The victim cannot simply appear at the crisis.
   - The script must show the proof, witness, document, object, or timing that
     made the accusation believable.

3. Use planted or distorted evidence.
   - The frame should involve at least two of these: object, person, document,
     timing, motive.
   - Strong examples: blood writing, planted keepsake, false witness, altered
     ledger, missing stroke, forged seal, staged footprint.

4. Make the victim ordinary enough to project onto.
   - The viewer must feel "this could happen to a normal person."
   - Avoid making the victim so passive that the story feels accidental.

5. Give the discoverer a reason to notice.
   - Clerk, widow, old witness, child, servant, bank employee, or another
     overlooked figure.
   - The discoverer should have experience, suspicion, habit, or access that
     makes the discovery believable.

6. No single-clue villain jump.
   - Do not go from one clue directly to the villain.
   - Use the chain: clue -> question -> recheck -> second clue -> motive ->
     villain confirmation.

7. Villain motive must create gain.
   - Money, debt, rank, shame, inheritance, revenge, silence, or protection of
     another person.
   - "He was evil" is not enough.

8. Payoff must recover the opening loop.
   - The punishment or reversal is not enough.
   - Return to the first object, written mark, line, document, or scene and show
     what it really meant.

## Recommended Four-Beat Layout

```text
Beat 1. 처형/위기
- Start with the irreversible moment.
- Open the main question.

Beat 2. 억울
- Show how the victim was trapped.
- Reveal planted proof or distorted testimony.

Beat 3. 빌런 발견
- Introduce the discoverer with a three-beat entry.
- Build the clue chain without skipping logic.

Beat 4. 통쾌
- Clear the victim.
- Expose the villain's motive.
- Recover the opening anchor.
- End with a concrete action or memory.
```

## Clue Chain Pattern

```text
Visible clue
-> why it is strange
-> recheck against the original source
-> contradiction appears
-> who had access
-> who gained
-> villain confirmed
```

## Yadam Example Frame

```text
Opening: a man is about to be executed.
Why caught: blood writing names him, and a witness confirms he passed the inn.
Planted proof: the blood writing missed one stroke; a keepsake was placed.
Discoverer: an old clerk who always checks copied records twice.
Clue chain: blood writing -> victim could not write -> copied name differs ->
false witness was paid -> clerk's ledger shows the payer.
Payoff: the written mark that condemned the man becomes the mark that exposes
the villain.
```
