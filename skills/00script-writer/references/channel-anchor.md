# Channel Anchor

Use this when designing repeatable channel formats or making a script fit an existing channel identity.

A memory anchor belongs to one video. A channel anchor belongs to every video.

## Required Output

```text
Channel Anchor
- Fixed opening element:
- Repeated object or action:
- Signature phrase:
- Common visual cue:
- Ending recovery:
```

## Rules

- The channel anchor must appear in every video or every episode family.
- It must be easy to repeat without sounding forced.
- It must connect to the channel promise, not just branding.
- It should help the viewer recognize the channel before seeing the logo.
- Do not make the channel anchor a generic "like and subscribe" phrase.

## Anchor Types

- **Opening line**: a repeated sentence that frames the channel's worldview.
- **Object**: phone, calendar, seal, gate, button, ledger, receipt, chair, family password.
- **Action**: stop before clicking, check the official number, open the calendar, look at the erased name.
- **Visual cue**: stamp, freeze frame, courtroom table, dark phone screen, old document, red warning light.
- **Closing recovery**: the ending returns to the same phrase or object.

## Channel Families

### Scam Prevention

```text
Channel anchor: "끊고, 다른 전화기로 확인하세요."
Object: phone separated from the suspicious call
Visual cue: phone pushed away
```

### Finance / Stocks

```text
Channel anchor: "버튼 앞에서 3초."
Object: buy/sell button
Visual cue: finger stopped over the screen
```

### History

```text
Channel anchor: one erased name, one sealed gate, one royal command
Visual cue: document, seal, palace gate
```

### Mindset / Relationship

```text
Channel anchor: one sentence the viewer can use today
Object: calendar, message draft, contact name
```

### Sassy / Revenge

```text
Channel anchor: proof appears before judgment
Object: recording, receipt, CCTV, contract, witness
```
