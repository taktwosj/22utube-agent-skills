# Intent Anchor

## Purpose

Use this before drafting longform or midform scripts. Decide what the viewer
should feel, learn, and do before writing any script body.

The category is not the emotion. The category is the information field; emotion
is the entry force; action is the ending payoff.

## Required Card

```text
[Intent Anchor]
- Primary Emotion:
- Information Goal:
- Action Trigger:
- Share Target:
- One-Month Memory:
```

### Primary Emotion

Choose exactly one primary emotion:

```text
분노 / 공포 / 연민 / 통쾌 / 감동 / 궁금증 / 경각심 / 자기변호 / 배신감 / 씁쓸함
```

Secondary emotions may exist, but they must not compete with the primary
emotion.

### Information Goal

Write one fact, structure, pattern, warning, or idea the viewer newly learns.
Education, health, finance, business, tech, and history belong here.

### Action Trigger

Write one concrete action the viewer may take within 24 hours after watching.

Valid verbs include:

```text
확인한다 / 저장한다 / 공유한다 / 비교한다 / 예약한다 / 댓글을 단다 / 따라한다 / 검색한다 / 점검한다
```

Invalid action goals:

```text
좋아요 / 구독 / 조심하세요 / 기억하세요 / 깨닫는다 / 느낀다
```

### Share Target

Name who the viewer would send this to. Use a concrete group such as `부모님`,
`배우자`, `계 모임 하는 사람`, `구매 고민 중인 친구`, or `같은 게임 하는 친구`.

### One-Month Memory

Name one word, object, number, sentence, or scene that should remain after one
month.

## Rules

1. Fill the Intent Anchor before drafting.
2. Primary Emotion must be exactly one.
3. Information Goal must be exactly one.
4. Action Trigger must be a real viewer action.
5. Like/subscribe is never the Action Trigger.
6. "Be careful" and "remember this" are not actions.
7. If Primary Emotion, Information Goal, or Action Trigger is empty, do not
   draft.
8. A category preset is only a starting point. The video-specific Intent Anchor
   always wins.

## Example

Topic: 조선 장터 곗돈 먹튀

```text
[Intent Anchor]
- Primary Emotion: 경각심
- Information Goal: 조선 서민도 계, 장부, 신뢰 구조 때문에 돈을 잃을 수 있었다.
- Action Trigger: 돈 모임, 계, 투자방, 지인 돈거래에서 장부, 운영자, 공개 규칙을 확인한다.
- Share Target: 부모님, 계 모임 하는 사람, 지인 투자 권유 받은 사람
- One-Month Memory: 빨간 보자기
```

Identity:

```text
슬픈 조선 이야기가 아니라 조선판 금융사기 경고담.
```
