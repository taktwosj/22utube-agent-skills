# Memory Anchor And Reward Loop

Use this reference when designing a new script, fixing a generic script, or deciding whether to park a topic.

## Anchor Test

A memory anchor is the one thing the viewer remembers after the video. It must be concrete.

Good anchor types:

- **Number**: 3 seconds, 2000억, -30%, 4.7 seconds
- **Object**: 매수 버튼, 축의금 봉투, ATM screen, phone calendar
- **Action**: check calendar, call official number, pause before buy, ask the family password
- **Sentence**: "일정 확인하고 말할게", "우리 암호 뭐야?"
- **Image/sound**: one gunshot, phone ringing, a hand stopped over a contact name

Do not use a clever new phrase if viewers will not meet it again. Prefer existing objects and actions.

## Anchor Score

Score 0-2 each:

1. **Everyday trigger**: will the viewer encounter it again?
2. **Actionable**: does it make the viewer do something?
3. **Simple**: can it be named in one phrase?
4. **Connected**: does it solve or explain the topic?
5. **Recoverable**: can it return in the ending?

8+ = write. 5-7 = reframe. 0-4 = park.

## Placement

```text
0:00-0:30  introduce the anchor
0:30-3:00  prove why it matters
3:00-80%   loop through examples/reasons
ending     return to the anchor as one action or one sentence
```

## 10-Second Reward Loop

Do not run a school-essay structure. Run a reward loop.

```text
0:00  anchor or irreversible moment
0:10  first meaning
0:20  stranger detail
0:30  small proof
0:45  bigger question
1:00  video promise
```

For a 5-10 minute script, every minute needs a reason to stay:

- new question
- concrete number
- strange detail
- evidence
- action step
- emotional reversal
- result preview

## Examples

### 보이스피싱

Anchor: 가족 암호

Opening:

```text
좋아하는 음식 하나만 떠올려보세요.
이 단어가 오늘 영상 끝에서 가족 돈을 지키는 암호가 됩니다.
```

Ending:

```text
아까 떠올린 단어를 그대로 쓰라는 뜻은 아닙니다.
가족만 알고 남은 못 맞히는 이상한 단어로 바꾸세요.
누가 가족인 척 돈을 요구하면 묻는 겁니다.
"우리 암호 뭐야?"
```

### 부탁 거절

Anchor: 휴대폰 캘린더

```text
부탁받으면 바로 대답하지 마세요.
휴대폰을 꺼내고 캘린더를 여세요.
"일정 확인하고 말할게."
```

### 주식

Anchor: 매수 버튼 앞 3초

```text
급등 뉴스를 보고 손가락이 매수 버튼 위에 올라갔다면,
3초만 멈추세요.
나는 투자하는 건가, 놓친 기분을 지우는 건가.
```

### 노년 가난

Anchor: 축의금 봉투

```text
노후를 무너뜨리는 돈은 항상 큰돈처럼 오지 않습니다.
가끔은 하얀 축의금 봉투 하나로 옵니다.
```

### 형제 갈등

Anchor: 연락처에서 멈춘 손가락

```text
오늘 밤 연락처를 내려보다가 손가락이 멈추는 이름이 있다면,
바로 전화하지 마세요.
먼저 보내지 않는 편지 한 장을 쓰세요.
```
