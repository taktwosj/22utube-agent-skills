# Angle Pivot

Use this when a topic is inspired by an already-viral video, news item, source clip, competitor script, or repeated trend.

The goal is not to hide copying. The goal is to create a new viewer promise by changing the angle before writing.

## Required Output

Before writing, output:

```text
Angle Pivot
- Source angle:
- Chosen pivot:
- Why this pivot wins:
- What must not be copied:
- New memory anchor:
```

## Pivot Dimensions

Choose one primary pivot. Do not stack all of them.

1. **Time**: before, after, during, or the delayed consequence of the source moment.
2. **Person**: secondary character, witness, victim, offender, family member, official, silent observer.
3. **Place**: inside the room, behind the counter, courtroom, phone call, chat room, bank app, palace gate.
4. **Decision**: the 0.3-second choice, the one button, the one sentence, the one ignored warning.
5. **Mechanism**: invisible cause, incentive, procedure, scam step, power structure, psychological trap.
6. **Opposite View**: villain logic, institutional view, missed-buyer view, trapped-holder view, bystander view.

## Hard Rules

- Do not copy the source title structure, opening sequence, visual order, punchline, or final lesson.
- If the source is a visual clip, the new script must point to a different object, action, or timing.
- If the source is a story, the new script must choose a different irreversible moment.
- If no meaningful pivot exists, park the topic or make it a review/analysis piece instead of a remake.

## Examples

```text
Source: "Police scam call recording"
Bad angle: "This is a voice phishing scam."
Pivot: Decision
New angle: "The call sounds real until the moment they ask your balance."
Anchor: balance question
```

```text
Source: "Historical king betrayed his nephew"
Bad angle: broad biography
Pivot: Place
New angle: "What changed inside the sealed palace gate that night?"
Anchor: sealed gate
```

```text
Source: "Stock skyrocketed 200%"
Bad angle: why it rose
Pivot: Opposite View
New angle: "The person who sold yesterday is not angry because of price. They are angry because of the button."
Anchor: sell button
```
