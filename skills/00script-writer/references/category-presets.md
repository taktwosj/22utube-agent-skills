# Category Presets

## Core Rule

Category presets are drafting defaults only. The video-specific Intent Anchor
always wins.

If Q3 Memory Anchor or Q4 First-30-Second Retention fails, revise even when the
overall 70 percent rule passes.

```text
카테고리 = 어떤 정보를 줄 것인가
감정 = 왜 계속 보게 할 것인가
행동 = 보고 나서 무엇을 하게 할 것인가
앵커 = 한 달 뒤 무엇이 남을 것인가
게이트 = 10명이 행동 / 공유 / 기억을 예측하는가
```

Every video should define:

```text
1. Primary Emotion
2. Information Goal
3. Action Trigger
4. Share Target
5. One-Month Memory
```

Do not use like/subscribe as the Action Trigger.

## 1. 게임

Default:

```text
Primary Emotion: 통쾌 / 궁금증 / 몰입
Information Goal: 플레이 구조, 공략, 반전, 캐릭터/장비 차이
Action Trigger: 댓글로 경험을 말하거나 직접 플레이/비교한다
Share Target: 같은 게임 하는 친구
One-Month Memory: 결정적 플레이 장면 / 캐릭터 / 한 방 역전
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 액션 게임 | 통쾌 | 컨트롤/전투 상황 이해 | 나도 해본다 |
| RPG 게임 | 몰입 | 성장/아이템/빌드 이해 | 빌드 저장, 캐릭터 비교 |
| 전략 게임 | 지적 우월감 | 판단 근거/전략 구조 | 자기 전략 점검 |
| 시뮬레이션 | 궁금증 | 시스템 결과 확인 | 조건 바꿔보기 |
| 스포츠/레이싱 | 승부욕 | 기록/기술 차이 | 기록 비교 |
| 퍼즐 | 지적 쾌감 | 풀이 원리 | 정답 댓글 |
| 음악 게임 | 리듬 쾌감 | 난이도/콤보 포인트 | 플레이 도전 |

Hook examples:

```text
이 장면 하나 때문에 게임이 뒤집혔습니다.
이걸 모르면 같은 장비를 써도 집니다.
99%가 여기서 실수합니다.
```

## 2. 교육 / 비즈니스

Default:

```text
Primary Emotion: 깨달음 / 자기점검 / 경각심
Information Goal: 몰랐던 개념, 구조, 돈/일/사람의 작동 원리
Action Trigger: 자신의 일, 돈, 습관, 계약, 말투를 점검한다
Share Target: 직장 동료, 사업하는 친구, 배우자
One-Month Memory: 숫자 1개 / 문장 1개 / 체크리스트 1개
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 지식 | 깨달음 | 몰랐던 원리 이해 | 저장, 검색 |
| 비즈니스 | 경각심 | 돈/일/조직 구조 이해 | 계약, 가격, 고객관리 점검 |

Hook examples:

```text
대부분 이걸 실력 문제라고 착각합니다.
돈을 못 버는 이유는 노력 부족이 아닙니다.
이 한 가지를 모르면 계속 손해 봅니다.
```

## 3. 뉴스 / 사회

Default:

```text
Primary Emotion: 분노 / 경각심 / 씁쓸함
Information Goal: 사건의 구조, 이해관계, 숨은 원인
Action Trigger: 관련 이슈를 확인하거나 주변에 경고한다
Share Target: 가족, 친구, 같은 문제를 겪을 사람
One-Month Memory: 사건을 상징하는 장면 / 숫자 / 발언
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 사회 | 경각심 | 사건 구조 이해 | 주변에 공유 |
| 정치 | 분노 / 불신 | 권력 구조 이해 | 입장 정리, 토론 |
| 종교 | 조심스러움 / 경계 | 믿음과 조직 구조 이해 | 확인, 거리두기 |
| 군사 | 긴장감 / 경각심 | 전력, 전략, 위험 이해 | 자료 검색, 공유 |

Hook examples:

```text
이 사건이 무서운 이유는 따로 있습니다.
사람들이 분노한 진짜 이유는 이것입니다.
겉으로는 작은 사건처럼 보였습니다.
```

## 4. 라이프 / 건강

Default:

```text
Primary Emotion: 자기점검 / 경각심 / 공감
Information Goal: 생활 속 위험, 습관, 몸의 신호, 개선법
Action Trigger: 몸, 습관, 집안 상태를 확인한다
Share Target: 부모님, 배우자, 친구, 자녀
One-Month Memory: 증상 1개 / 습관 1개 / 체크 행동 1개
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 일상 | 공감 | 일상의 불편 구조 이해 | 댓글, 공유 |
| 취미 | 즐거움 / 대리만족 | 취미 시작 방법 | 저장, 따라하기 |
| 음식 | 식욕 / 호기심 | 맛, 조리법, 가성비 | 먹어보기, 저장 |
| 건강 | 경각심 | 위험 신호, 관리법 | 증상/검진/약 확인 |
| 피트니스 | 자기점검 | 운동 자세, 루틴 | 오늘 1세트 따라하기 |

Hook examples:

```text
이 증상, 그냥 피곤해서가 아닐 수 있습니다.
많은 사람이 이 습관을 건강한 줄 압니다.
오늘 딱 하나만 확인하세요.
```

## 5. 뷰티 / 패션

Default:

```text
Primary Emotion: 변화 기대 / 자기확신 / 비교 욕구
Information Goal: 스타일, 제품, 조합, 실수 포인트
Action Trigger: 옷장, 화장품, 스타일을 점검한다
Share Target: 친구, 연인, 결혼/면접/촬영 준비하는 사람
One-Month Memory: 전후 비교 장면 / 컬러 / 아이템
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 패션 | 자기확신 | 체형/색/아이템 조합 | 옷장 점검 |
| 뷰티 | 변화 기대 | 제품/피부/메이크업 팁 | 제품 비교, 따라하기 |

Hook examples:

```text
이 옷이 안 어울리는 이유는 몸매가 아닙니다.
얼굴이 달라 보이는 차이는 여기서 납니다.
이 조합 하나만 바꿔도 인상이 달라집니다.
```

## 6. 스포츠

Default:

```text
Primary Emotion: 승부욕 / 통쾌 / 감탄
Information Goal: 경기 흐름, 기술, 선수 차이, 기록 의미
Action Trigger: 하이라이트를 다시 보거나 댓글로 논쟁한다
Share Target: 같은 팀 팬, 운동하는 친구
One-Month Memory: 결정적 장면 / 기록 / 선수 이름
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 축구 | 감탄 / 분노 | 전술, 실수, 골 장면 | 댓글 논쟁 |
| 농구 | 통쾌 | 움직임, 슛, 매치업 | 하이라이트 재시청 |
| 야구 | 긴장감 | 기록, 투구, 수 싸움 | 기록 확인 |
| 복싱/격투기 | 원초적 긴장 | 타격, 방어, 심리전 | 경기 찾아보기 |
| 골프/테니스 | 기술 감탄 | 자세, 타이밍 | 자세 따라하기 |
| 모터스포츠 | 속도감 | 기록, 머신 차이 | 비교 영상 탐색 |

Hook examples:

```text
이 장면에서 승부는 이미 끝났습니다.
사람들이 놓친 진짜 실수는 이겁니다.
기록보다 무서운 건 이 움직임입니다.
```

## 7. 엔터테인먼트

Default:

```text
Primary Emotion: 웃김 / 궁금증 / 감동 / 통쾌
Information Goal: 장면의 의미, 인물 관계, 숨은 맥락
Action Trigger: 원본을 찾아보거나 댓글로 해석을 남긴다
Share Target: 같은 취향 친구, 팬덤, 가족
One-Month Memory: 대사 / 표정 / 반전 장면
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 엔터 일반 | 재미 / 궁금증 | 인물, 사건 맥락 | 댓글 |
| 영화/애니 | 몰입 / 감동 | 장면 해석, 세계관 | 원작 찾아보기 |
| 코미디/유머 | 웃김 / 통쾌 | 상황의 반전 이해 | 공유 |
| TV 프로그램 | 친근감 | 출연자 관계, 명장면 | 클립 더 보기 |
| 공연 예술 | 감탄 | 실력, 표현, 무대 의미 | 저장, 공유 |
| 프로레슬링 | 통쾌 / 과몰입 | 서사, 대립 구조 | 팬 반응 댓글 |

Hook examples:

```text
이 장면이 웃긴 이유는 따로 있습니다.
처음 보면 그냥 웃기지만, 알고 보면 무서운 장면입니다.
이 대사 하나가 캐릭터를 다 설명합니다.
```

## 8. 여행 / 반려동물

Default:

```text
Primary Emotion: 힐링 / 귀여움 / 대리만족 / 보호본능
Information Goal: 장소, 동물 행동, 돌봄 포인트
Action Trigger: 저장, 공유, 방문 계획, 반려동물 상태 확인을 한다
Share Target: 가족, 연인, 반려동물 키우는 사람
One-Month Memory: 귀여운 행동 / 장소 / 표정
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 반려동물 | 귀여움 / 보호본능 | 행동 의미, 돌봄 포인트 | 공유, 댓글 |
| 여행 | 대리만족 / 설렘 | 장소, 비용, 동선, 주의점 | 저장, 방문 계획 |

Hook examples:

```text
강아지가 이 행동을 하면 그냥 귀여운 게 아닙니다.
이 여행지는 사진보다 실제가 더 이상합니다.
고양이가 갑자기 이런 표정을 지은 이유.
```

## 9. 음악

Default:

```text
Primary Emotion: 감동 / 추억 / 흥분 / 몰입
Information Goal: 곡의 포인트, 가수의 표현, 장르 차이
Action Trigger: 원곡 듣기, 플레이리스트 저장, 추억 댓글을 남긴다
Share Target: 같은 가수 팬, 친구, 연인
One-Month Memory: 후렴 / 가사 한 줄 / 무대 장면
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 팝 음악 | 흥분 / 감성 | 후렴, 퍼포먼스 | 원곡 듣기 |
| 아시아 음악 | 팬심 / 감동 | 가수, 무대, 서사 | 팬 공유 |
| 힙합 | 통쾌 / 자기표현 | 가사, 플로우, 디스 맥락 | 댓글 논쟁 |
| 라틴/일렉 | 흥 | 리듬, 분위기 | 저장, 반복재생 |
| 록/인디 | 해방감 / 감성 | 사운드, 메시지 | 플레이리스트 추가 |
| 클래식/재즈 | 감탄 / 안정감 | 연주 포인트 | 저장, 배경음악 사용 |

Hook examples:

```text
이 노래가 계속 생각나는 이유는 후렴이 아닙니다.
이 무대는 실력보다 감정선이 무섭습니다.
처음 3초에 이미 곡의 승부가 끝납니다.
```

## 10. 테크 / 자동차

Default:

```text
Primary Emotion: 궁금증 / 구매욕 / 경각심 / 감탄
Information Goal: 기능, 성능, 가격, 위험, 비교 포인트
Action Trigger: 제품 비교, 구매 전 체크, 댓글 질문을 한다
Share Target: 구매 고민 중인 사람, 차 좋아하는 친구, 가족
One-Month Memory: 기능 1개 / 결함 1개 / 숫자 1개 / 주행 장면
```

Subcategories:

| 세부 카테고리 | 기본 감정 | 정보 목적 | 행동 |
| --- | --- | --- | --- |
| 테크 | 궁금증 / 구매욕 | 기능, 성능, 차이 | 비교 검색 |
| 자동차 | 감탄 / 경각심 | 주행감, 결함, 유지비 | 구매 전 점검 |

Hook examples:

```text
이 기능 때문에 사람들이 착각합니다.
스펙표에는 안 나오는데 실제로는 이게 차이 납니다.
차를 사기 전에 이 숫자 하나는 봐야 합니다.
```

## User Channel Priority Defaults

| 분야 | 추천 기본 감정 | 추천 행동 |
| --- | --- | --- |
| 역사 야담 | 경각심 / 연민 / 배신감 | 가족, 지인에게 공유 |
| 경제/투자 조언 | 경각심 / 자기점검 | 매수 전 체크리스트 확인 |
| 건강/운동 | 경각심 / 자기점검 | 증상, 운동자세, 검진 확인 |
| 반려동물 쇼츠 | 귀여움 / 보호본능 | 공유, 댓글 |
| 실험/기묘한 영상 | 궁금증 / 감탄 | 원본 확인, 댓글 |
| 사이다/막장 | 분노 / 통쾌 | 댓글, 공유 |
