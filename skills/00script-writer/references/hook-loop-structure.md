# Hook-Loop Structure

Use this as the universal retention layer for direct-made scripts. It sits
above category templates and below the user's channel intent.

The goal is not to create many unrelated mysteries. The goal is one main open
loop, with smaller rewards that keep returning to the same object, person,
question, number, or scene.

## Required Card

```text
[Hook-Loop Structure]
- Opening contradiction:
- First visible scene:
- Main open loop:
- First 30s hold question:
- Small reward before 30s:
- Remaining question after 30s:
- Loop recovery beats:
- Final recovery:
```

## Big Structure

1. Start with a contradiction.
   - Small thing -> huge consequence.
   - Ordinary person -> impossible punishment.
   - Good result -> bad feeling.
   - Familiar action -> hidden danger.

2. Show before explaining.
   - Start with a scene, object, number, line, or action.
   - Do not start with category background.
   - The viewer should ask "why did this happen?"

3. Open one main loop.
   - Examples: Why was he at the execution ground? Who planted the proof? Why
     did one written mark matter?
   - The loop must be answerable by the script, not vague atmosphere.

4. Reward every 10 to 30 seconds.
   - Give a clue, reversal, object, witness, number, document, or visible action.
   - Each reward should answer one small question and create the next precise
     question.

5. Recover the opening.
   - The ending must return to the first object, sentence, number, or scene.
   - The final line should make the viewer remember or do one concrete thing.

## Anti-Patterns

- Opening with a shocking scene, then never returning to it.
- Explaining the whole premise before giving a visible object.
- Solving the big question with a single unsupported leap.
- Creating five mysteries that do not converge.
- Ending only with punishment, without recovering the opening anchor.

## Loop Beat Example

```text
Opening: 사형장. "멈추시오."
Loop 1: 왜 잡혔나?
Reward 1: 피로 쓴 이름이 있었다.
Loop 2: 그런데 누가 썼나?
Reward 2: 피해자는 글을 몰랐다.
Loop 3: 그럼 누가 손을 움직였나?
Reward 3: 조작된 증언과 이방의 동기가 만난다.
Final recovery: 처음 피로 쓴 글자가 빌런의 덫이었다.
```
