# 군림보 운영자 참고 이미지 → Image2 만화화 및 정확한 텍스트 카드

## 적용 조건

- 운영자가 `군림보`, `블랙 TOP5`, `TOP55`, `이 사진으로 만화이미지`, `내가 주는 이미지들을 지피티에 다시 줘`라고 말한 경우.
- 주제가 순위형이 아니어도 `군림보`가 명시되면 `style_profile=gunlimbo`, `template_profile=top5isu_v2_top55`를 사용한다.
- 일반 `0short`, `shrt white`, 로컬 PIL 카드, 텍스트 프롬프트만으로 만든 대체 이미지는 이 경로의 최종물이 아니다.

## 장면별 참고 이미지 수신

1. 첨부 원본을 변경 없이 `40_assets/references/operator/`에 보존한다.
2. 장면 ID, 운영자 설명, 크기, 바이트, SHA-256, 보이는 글자·로고·워터마크를 manifest에 기록한다.
3. 운영자의 최신 명시적 장면 매핑이 우선한다. 설명 없는 수신 순서로 장면을 추정하지 않는다.
4. 이전 Image2 후보가 있더라도 새 운영자 참고 이미지가 들어오면 `SUPERSEDED_BY_OPERATOR_REFERENCE`로 보존 이동하고 해당 장면만 재생성한다.
5. 한 참고 카드가 두 사실 장면을 포함하면 억지로 한 이미지에 넣지 말고 장면별로 분리한다.

## 정식 Image2 생성

1. 일반 ChatGPT 새 채팅을 사용한다. 임시 채팅은 이미지 생성이 제한될 수 있으므로 사용하지 않는다.
2. 장면에 매핑된 원본을 실제 ChatGPT composer에 첨부한다. 텍스트 프롬프트에서 '참고했다'고만 쓰는 것은 불충분하다.
3. 프롬프트는 원본의 구도·장소·소품·감정만 참고하고, 식별 가능한 얼굴·브랜드 글자·뉴스 카드 문구를 그대로 복제하지 않도록 한다.
4. `top5isu_v2_top55`의 현재 투명 창을 먼저 측정한다. 기본 창은 `966×794`, 약 `1.2166:1`이며 생성물은 풀블리드, 검은 레터박스 없음, 중앙 안전 구도로 요청한다.
5. 첫 장은 실제 Image2 샘플 → `966×794` 정규화 → 실제 TOP55 프레임핏 미리보기 → 운영자 승인 순으로 진행한다. 승인 전에는 나머지를 배치 생성하지 않는다.
6. 승인 후 장면별로 새 채팅 또는 문맥이 섞이지 않는 독립 요청을 사용한다.

## 정확한 한글·숫자 분리

- 운영자가 `이미지와 함께 텍스트`를 요청해도 Image2가 긴 한국어·날짜·숫자를 직접 그리게 하지 않는다.
- Image2에는 인물·행동·상징·빈 텍스트 안전영역을 생성한다.
- 검증된 한국어와 숫자는 CapCut의 `SOURCE_TEXT`/`TTS_TEXT`/제목 트랙 또는 결정론적 검수 오버레이로 넣는다.
- 사용자 참고 카드의 문구는 사실 출처와 잠금 대본에 대조한 뒤 사용한다. 작은 글자·깨진 OCR·로고는 복사하지 않는다.
- 예: 과로 장면은 지친 성인 직원·시계·근태서류를 Image2로 만들고, `주 70시간 이상 근로 6명`, `최대 주 82시간 30분 근로` 같은 검증 숫자는 별도 텍스트로 넣는다.

## CDP 첨부 이미지 오인 방지

참고 이미지를 composer에 첨부하면 DOM에 `/backend-api/estuary/content` 이미지로 나타날 수 있다. 단순히 '새 estuary 이미지'를 기다리는 러너는 업로드 원본을 생성 결과로 오인할 수 있다.

필수 방지책:

1. 프롬프트 제출 전에 첨부 원본의 SHA-256, 파일 크기, 픽셀 크기와 현재 DOM 이미지 URL 집합을 기록한다.
2. 생성 후보는 첨부 원본과 동일한 크기·바이트·해시를 거부한다.
3. ChatGPT 생성 중지 버튼이 사라질 때까지 기다린다. 첨부 썸네일이 먼저 나타났다고 저장하지 않는다.
4. 최종 후보는 생성 UI에서 나온 고해상도 이미지인지 확인한다. TOP55 Image2의 정상 사례는 약 `1383×1137`이지만 특정 크기를 절대값으로 하드코딩하지 말고, 업로드 원본보다 충분히 크며 generated-image URL이고 고유 해시인지 함께 검증한다.
5. 잘못 저장한 첨부 원본은 즉시 삭제하고 실제 생성 완료 후 마지막 유효 생성 이미지를 브라우저 인증 문맥에서 다시 저장한다.
6. 원본과 생성본의 SHA-256이 달라야 하며, 저장 후 실제 크기와 바이트를 다시 읽는다.

## 운영자 시각 교정은 재생성 게이트

- `피켓은 들게 하지 마`, `손에 아무것도 들지 마`처럼 금지 객체를 지정하면 기존 Image2를 로컬 지우개·인페인트·크롭으로 수선하지 않는다. 기존 파일은 `REJECT_<REASON>`으로 보존하고 참고 원본을 다시 첨부해 Image2를 재생성한다.
- 프롬프트에는 금지 대상을 일반 표현 하나로 끝내지 말고 구체적으로 열거한다. 예: `no placards, picket signs, boards, paper sheets, banners, flags, poles, or handheld objects`; 손은 아래로 내리거나 주머니·팔짱 자세로 지정한다.
- 새 결과에서 금지 객체 수가 0인지 실제 픽셀로 다시 확인한다. 사용자 시각 교정은 자동 PASS보다 우선한다.

## TOP55 에피소드 레이아웃 교정

운영자가 로고·자막 위치를 직접 고치면 불변 root를 수정하지 말고 episode-level machine-readable override로 기록한다.

- 정보있슈 로고 고정값은 CapCut UI `Scale 50%, X 0, Y 1500`이다. JSON에서는 `scale.x=0.5`, `scale.y=0.5`, `transform.x=0`, `transform.y=0.78125`로 기록하고 T1/T2와 겹치지 않는지 확인한다.

### CapCut 로컬 이미지 캐시 충돌 방지

템플릿의 stock image material을 복제해 경로만 바꾸면, 실제 PNG 해시가 정상이어도 CapCut이 이전 stock thumbnail/preview를 모든 장면에 반복 표시할 수 있다.

- 이미지 파일은 장면 번호와 콘텐츠 해시가 포함된 새 이름으로 저장한다.
- `materials.videos`의 각 이미지에 서로 다른 고유 `material_id`를 부여한다.
- 상속된 `category_id`, `category_name`, `material_url`은 비우고 `source=0`, `source_platform=0`, `check_flag=0`, `is_copyright=false`로 로컬 material화한다.
- stock 설명이 든 `key_value.json`은 `{}`로 초기화한다.
- stale `.bak`, `template-2.tmp`, `Timelines/*/attachment/patch`가 이전 stock metadata를 되살리지 않도록 제거하거나 최신 authority로 재생성한다.
- 원본 PNG 해시 확인만으로 PASS하지 않는다. CapCut을 실제로 열어 미리보기와 타임라인 썸네일이 서로 다른 승인 이미지 N/N으로 보이는지 확인한다.

### CapCut 저장 authority와 클라우드 업로드

- UI에서 transform을 수정한 직후 `draft_content.json`이 이전 값일 수 있다. 자동 저장 후 편집기를 닫고 최신 `draft_info.json` 또는 `template-2.tmp`를 읽어 UI 값과 일치하는 authority를 선택한 뒤 full-content mirror를 맞춘다.
- 클라우드 중복 업로드는 로컬 폴더와 프로젝트명을 `(1)`처럼 바꿀 수 있다. 업로드 후 `root_meta_info.json`에서 실제 `draft_fold_path`, `draft_name`, `draft_id`를 다시 읽고 validator와 assembly report에 최신 경로를 사용한다.
- 지정 폴더 업로드는 해당 클라우드 폴더에서 `업로드 → 프로젝트 업로드`로 로컬 프로젝트를 선택한다. 홈의 우클릭 업로드는 기존 연결에 따라 `자동 업로드`로 갈 수 있으므로 목적지 검증을 생략하지 않는다.
- 완료 판정은 클라우드 행의 이름·크기·길이·유형·최근 편집·오류/진행 상태를 읽은 뒤에만 한다. 중복된 이전 결함본은 명시적 삭제 승인 없이 제거하지 않는다.

- 현재 TOP55 미디어 창은 `x54..1019, y514..1307`이다.
- `자막을 이미지 바로 밑으로`는 고정 21px 간격을 사용해 첫 TTS bbox top을 약 `y=1328`에 둔다. 자막 y 좌표를 임의의 하단 기본값으로 되돌리지 않는다.
- 로고 확대와 자막 이동을 적용한 1080×1920 실제 프레임 미리보기를 다시 전달하고 승인 전에는 CapCut 전체 적용을 잠근다.

## QA

- 실제 Image2 PNG 수와 준비된 프롬프트 수를 구분해 보고한다.
- 원본·raw Image2·정규화 PNG의 해시를 각각 보존한다.
- 검수 항목: 원본 장면 의미, 만화 스타일, 성인 인물, 손·팔다리 왜곡, 깨진 글자, 로고·워터마크, 레터박스, 중앙 크롭 안전성.
- 운영자 참고 이미지가 들어온 장면은 텍스트 전용 프롬프트 생성본보다 우선한다.
- 시위·과로·과태료 같은 민감 장면은 폭력·사망을 직접 묘사하지 않는다. 시위 장면은 운영자 요청에 따라 빈손 관찰자만 쓰고 피켓·현수막·종이·봉을 금지하며, 과로·과태료 장면은 시계·서류·사람이 아닌 문서에 내려치는 의사봉 같은 비폭력 편집 상징을 사용한다.
