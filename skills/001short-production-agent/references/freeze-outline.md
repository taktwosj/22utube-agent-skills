# 정지 화면과 노란 인물 외곽선

사용자가 정지·누끼·노란선을 요청하면 이 경로를 사용한다. 이미지를 주지 않아도 승인된 영상에서 해당 프레임을 추출한다. 이미지 제공 여부를 이유로 연출을 생략하거나 새 승인을 반복 요청하지 않는다.

## 조립 방식

- 원본표와 우라까이표, source-time 근거, 승인된 편집안은 계속 필요하다. 누락은 먼저 보완하며 별도 조립 코드로 검증을 우회하지 않는다.
- 기존 `user_provided_media_overlay` image 항목에 `match_video_geometry: true`를 넣는다. 기존 사용자 지시를 `user_authority`에 기록하고 이미지 경로·SHA·크기·목표 시간을 잠근다. agent가 만든 이미지도 그 지시의 파생 에셋으로 선언한다.
- 정지 구간은 한 VIDEO 세그먼트 안에 둔다. 전체 배경을 유지한 정지 이미지가 아래 움직이는 화면을 덮으므로 시각적으로 정지한다. B/V 길이·순서·전체 길이는 바뀌지 않는다. 시간을 추가하는 삽입 정지나 속도 변경은 이 경로가 지원하지 않는다.
- 해당 프레임의 원본 영상 경로·SHA·추출 시각을 에피소드 자료에 남긴다. 노란선은 실제 보이는 인물 외곽을 따라 굵은 단색으로 넣으며 다른 인물·얼굴·배경을 생성해 바꾸지 않는다.
- 정지 이미지의 픽셀 크기와 크롭 기준은 VIDEO와 같아야 한다. builder가 VIDEO의 clip transform/scale/crop을 복사한다. 영상은 그대로 100%를 유지하고 정지에 확대 팝·축소·별도 등장 줌을 붙이지 않는다. 다른 크기는 미리 영상과 같은 좌표계로 준비한다.
- 불투명 배경 정지 이미지와 투명 노란선 이미지를 나눌 때는 둘 다 같은 목표 시간과 `match_video_geometry: true`를 쓴다. 제목·상황설명·출처보다 아래, VIDEO보다 위에 놓는다. 기본 15트랙은 보존하고 추가 트랙은 기존 overlay layout에 선언한다.
- 클라이맥스 정지에는 편집 가능한 검정 대각선 상황설명을 함께 둔다. 이미지에 글씨가 박혀 있으면 같은 문장을 중복 배치하지 않는다. 승인된 색에서 문장별로 고정 선택, 각도는 −13°..−10° 또는 +10°..+13°에서 선택한다. 타이핑과 클릭음은 기존 자막/오디오 잠금에 기록한다. 얼굴·손·핵심 동작은 가리지 않는다.
- 원본 해설을 정지에 따라 재생하거나 새 TTS를 임의로 추가하지 않는다. 오디오는 승인된 정책 그대로 유지한다.

## 검증과 중단

`freeze_overlay_geometry`는 한 컷 내 배치·크기 일치·정적 VIDEO geometry를 확인한다. 1배 속도·빈 캔버스 등 확인된 정적 참조만 허용하며 실제 애니메이션·알 수 없는 효과는 실패한다. 새 원본으로 만든 VIDEO의 정지 대상 컷에서만 템플릿의 중첩 combination 참조를 제거하고 근본 ZIP은 변경하지 않는다. 실제 프로젝트 readback에서도 clip/crop·키프레임 없음·제목 아래 render order·로컬 미디어 SHA를 검사한다.

노란선 정합, 클린 처리로 망가진 얼굴·배경, 캡컷 실제 글자 가독성은 정적 JSON 검사만으로 PASS하지 않는다. CapCut이 열려 있으면 draft를 쓰지 않으며 정적 조립 후 `WAIT_USER_CAPCUT_CHECK`에서 사용자 검수를 기다린다. 렌더·업로드 승인은 별도다.
