## 2. 우라까이 구조 변경

### 2-0. 상황별 원본 구조 구분 — 순서 설계보다 먼저

구조 개수와 번호를 미리 정하지 않는다. 원본을 처음부터 끝까지 본 뒤 다음 변화점에서 구조를 나눈다.

- 상황·장소 변화
- 행동 목적 변화
- 주도 화자·대화 관계 변화
- 전달 방식 변화: 화자 발언/TTS/나레이션/효과음/영상 재생
- 서사 기능 변화: 도입/충돌/검증/행동/반전/결과/결말

| 원본 구조 | source range | 상황·행동 | 주도 화자 | 전달 방식 | 서사 기능 | 구조 분리 근거 |
|---:|---:|---|---|---|---|---|
| 구조 1 |  |  |  |  |  | 직전·다음 구간과 무엇이 달라지는지 기록 |

> 특정 구조의 A/B 분할은 필수가 아니다. 같은 원본 상황 안에서도 앞·뒤의 기능이 실제로 달라 별도 이동이 필요할 때만 사용한다.

- 원본 구조: `<상황별 분석 후 확정한 순서>`
- 최종 구조: `<예: 3→4→1→2→5>`

### 2-2. 원본 설계도 — 뒤에 표시

| 원본 시간 | 원본 구조 | 전달 방식 | 구조 유형 | 상황 설명 |
|---:|---:|---|---|---|
|  | 구조 1 | 화자 발언/단순 TTS/나레이션/효과음만/영상 재생만/복합형 | 도입/문제 제기/변명/대립/비교/검증/행동/결과/결말 |  |

> 전달 방식은 실제 A9/A10·현장음 구성을 기준으로 쓴다. A10 원본 음성이 살아 있으면 `영상 재생만`으로 표시하지 않는다.

> 원본 구조와 최종 구조가 같으면 `URAKKAI_STRUCTURE_UNCHANGED`로 중단한다. 제목·크롭·TTS 변경만으로 우라까이 승인을 내리지 않는다.
