# anticipation — 06 준비 동작

움직이기 직전에 반대쪽으로 0.15초 뺀다. 출발이 눈에 걸리게 만드는 최소 장치다.

## 대상과 시각

| 비트 | 대상 | 언제 |
|:--|:--|:--|
| `move` | 핀 `#b<i>_pin` | 경로 이동 시작(S+1.2) 직전 |
| `flow` | 패킷 `#b<i>_pk` | 첫 연결선 이동 직전 |
| `timeline` | 표식 `#b<i>_mk` | 레일을 타기 직전(S+0.35) |

```js
tl.fromTo('#b1_pin', {x:0}, {x:-16, duration:.15, ease:'power2.in',
                             immediateRender:false}, 12.3400);
```

## 지키는 것

- 후퇴 거리는 16px 이하. 더 빼면 되돌아오는 동작이 튄다.
- 본 이동 트윈이 시작하기 **전에** 끝나야 한다. `hf119/motion/fx.py` 의 `_flow_first_move` 가 `diagram/flow.py` 와 같은 식으로 시각을 계산한다. flow 쪽 계산식을 고치면 이 함수도 같이 고친다.
- `x` 만 쓴다. `left` 를 바꾸지 않는다.
- 이 동작은 강조로 세지 않는다. 기본 모션이다.
