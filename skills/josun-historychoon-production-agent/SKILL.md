# 역사춘 전용 스킬

역사춘은 단순 역사 지식 채널이 아니다. 조선·한국사의 권력, 배신, 충성, 복수, 궁중 비극, 잔혹한 형벌, 억울한 인물, 역사적 몰락을 45~58초 쇼츠 감정극으로 재구성하는 채널이다.

기본 목표:

```text
역사 소재 발굴 → 사실 축 정리 → 감정 훅 생성 → 제목 후보 생성
→ 썸네일 문구/이미지 프롬프트 생성 → 45~58초 쇼츠 대본 작성
→ 3텍스트 구조 설계 → 설명란/해시태그/고지문 생성 → 업로드용 패키지 완성
```

실제 이미지·TTS·CapCut·BGM 제작까지 진행하면 `0shrt-korea-production-agent` 규칙도 함께 적용한다. 이 스킬은 역사춘의 기획·제목·썸네일·대본·업로드 패키지를 전담하고, 0쇼츠 스킬은 GPT Image2, 음성, CapCut, 하네스 검수를 전담한다.

역사춘 제작에서 감정선 기반 CapCut 효과가 필요하면 `0shrt-korea-production-agent/references/capcut_emotion_effects.md`를 적용한다.

대본 초안 작성 후 최종 대본을 확정하기 전에는 `00script-writer/references/parallel-persona-gate.md`의 10페르소나 병렬 검수를 반드시 노출한다. 진행판과 요약표를 사용자에게 보여주고, `REWRITE_REQUIRED` 또는 `REPLAN`이면 수정 전에는 최종 대본으로 부르지 않는다.

## Shared Production Console Requirement

When this planning skill becomes actual YouTube production, every visible TODO/status report must include the full `A. n8n 실행` / `B. 하네스 검증` progress board from `22utube-production-agent`. Do not replace it with prose-only status.

역사춘이 기획 패키지를 넘어서 실제 유튜브 쇼츠 제작으로 진행되면 `22utube-production-agent`의 관제 시스템 규칙을 반드시 적용한다.

- 모든 유튜브 제작 보고는 `[ 진행판 ]`으로 시작한다: n8n 실행, 하네스 검증, 현재 막힌 곳, 다음 액션.
- 실제 제작 단계에서는 `phaseMap: 0shrt_original_production`을 사용한다. 11short `analysis/assets/capcut` 체크리스트로 역사춘 제작을 통과 처리하지 않는다.
- 실제 제작 증거는 0shrt 방식으로 본다: Image2 장면 이미지, `image2_manifest.json`, `audio/main_capcut.srt`, `audio/full_with_outro.mp3`, `video/capcut_draft_manifest.json`, validation/evidence/final report.
- `target: youtube_shorts`, `instagram_status: not_requested`를 기본 잠금으로 둔다.
- 사용자 검수와 하네스 PASS 전에는 파일명과 보고에 `REVIEW` 또는 `DRAFT`만 쓰고 `FINAL`은 쓰지 않는다.
- `$env:UTUBE_ROOT\tools\production_console`을 씬 단위 검수/수정 관제 도구로 사용한다.
- 씬 대본, SRT/자막, 음성/voice_id, Image2 프롬프트, 생성 이미지, BGM, 타이밍/레이아웃, 메모를 현재 에피소드 폴더의 `production_console.json`에 저장한다.
- 단계별로 `production_console.json`을 갱신한다: 대본, 음성, Image2, CapCut, 렌더, ffprobe, 프레임QA, FINAL 게이트.
- 로컬 제작이라 n8n 웹훅을 쓰지 않았으면 n8n 상태를 `WAIT`와 `local run; n8n webhook not invoked`로 표시한다. Compound 로그가 연결되지 않았으면 `WAIT - compound log not linked`로 표시한다.

아래 표현이 나오면 역사춘 흐름으로 들어간다.

```text
역사춘, 한국사 쇼츠, 조선 쇼츠, 역사 대본, 역사 제목, 역사 썸네일,
사육신, 세조, 단종, 영조, 사도세자, 장희빈, 연산군, 정순왕후,
혜경궁 홍씨, 부관참시, 궁중비사, 조선 왕실, 역사 사이다,

```

사용자가 인물이나 사건만 던져도 제목 10개, 썸네일 3안, 45~58초 대본, 설명란, 해시태그까지 하나의 패키지로 만든다.

## 채널 분리

역사춘에는 역사만 넣는다.

허용:

```text
조선사, 한국사, 삼국사, 고려사, 궁중비사, 왕실 권력, 형벌,
충신, 반역, 전쟁, 여성 인물, 민속·생활사
```

금지:

```text
시니어 건강, 기초연금, 생활용품, 쿠팡파트너스, 두뇌퀴즈,
암검진, 세제·주방 정보, 노후 조언
```

비역사 소재가 나오면 그대로 말한다.

```text
이 소재는 역사춘에 넣지 않는다.
더시니어/생활정보/복지 채널용으로 분리한다.
역사춘에서는 역사 소재만 제작한다.
```

## 핵심 공식

모든 영상은 이 감정 구조를 따른다.

```text
권력자/빌런이 선을 넘는다
→ 약자/충신/여인/왕자가 억울하게 당한다
→ 사건의 잔혹함이 드러난다
→ 반전 또는 역사적 대가가 나온다
→ 마지막에 한 줄 역사 교훈으로 닫는다
```

역사판 사이다 변환:

```text
현대 갑질녀 → 조선 권신
청소부 할머니 → 궁궐에서 버틴 약자
상남자 참교육 → 왕권/기록/역사의 심판
공개 망신 → 사약/폐위/부관참시/몰락
```

고정 무기:

```text
왕실 비극, 잔혹 형벌, 악녀로 몰린 여자,
끝까지 버틴 충신, 죽어서도 끝나지 않은 복수
```

## 길이와 구성

```text
기본: 45~58초
강한 사건: 최대 70초
2분 이상: 쇼츠 금지, 롱폼 또는 본편용
```

| 구간 | 역할 |
| --- | --- |
| 0~2초 | 충격 문장 |
| 2~8초 | 누가 누구를 건드렸는지 |
| 8~20초 | 권력/배신/억울함 증폭 |
| 20~35초 | 사건의 핵심 반전 |
| 35~50초 | 몰락/대가/의미 |
| 50~58초 | 역사춘식 한 줄 마무리 |

첫 문장은 설명이 아니라 사건으로 시작한다. 인사는 금지다.

```text
나쁜 시작: 혜경궁 홍씨는 조선 후기의 왕실 인물입니다.
좋은 시작: 남편이 뒤주 안에서 죽어가던 날, 그녀는 궁궐에서 아무 말도 할 수 없었습니다.
```

## 제목 규칙

제목은 교양 제목이 아니라 감정형 제목으로 만든다. 제목 후보는 항상 10개 출력한다.

```text
1~3번: 강한 자극형
4~6번: 궁금증형
7~8번: 감정형
9번: 역사 신뢰형
10번: 쇼츠 알고리즘형
```

좋은 제목 공식:

```text
{인물}이 끝까지 죽여야 했던 {대상}
{죽은 사람}을 다시 꺼내 벤 이유
{왕}이 {가족/충신/여인}에게 한 가장 잔인한 일
조선이 {인물}을 악녀로 만든 이유
{인물}이 살아남으려면 버려야 했던 것
{권력자}가 가장 두려워한 사람
왕이 선을 넘은 날
궁궐에서 가장 위험했던 한마디
```

피해야 할 제목:

```text
혜경궁 홍씨 궁궐을 고발한 기록자
잊혀진 고구려의 칼 3자루
조선 주막의 진짜 역할
정약용을 받아준 주막 방 한 칸
```

점잖은 교양 제목은 피한다. 정보보다 분노, 궁금증, 피 냄새가 먼저다.

## 썸네일 규칙

역사춘 썸네일은 `큰 얼굴 + 짧은 문구 + 강한 대비`만 쓴다.

문구:

```text
메인 문구: 4~9자
서브 문구: 6~14자
총 글자 수: 18자 이하
```

좋은 문구:

```text
또 베었다, 왕의 복수, 끝까지 충성, 사약의 날,
악녀가 된 왕비, 뒤주 속 비극, 세조의 공포, 죽어서도 벌
```

레이아웃:

```text
배경: 어두운 궁궐 / 피빛 노을 / 감옥 / 처형장 / 왕좌
인물: 한 명 또는 두 명만 크게
표정: 공포, 분노, 눈물, 냉정함
색상: 검정 + 붉은색 + 금색
글자: 흰색/노란색/붉은색 강한 외곽선
금지: 글자 3줄 이상, 작은 인물 여러 명, 밝고 평화로운 배경
```

항상 3개 안을 만든다.

```text
썸네일 A: 자극형
메인 문구:
서브 문구:
이미지 구성:
AI 이미지 프롬프트:

썸네일 B: 궁금증형
메인 문구:
서브 문구:
이미지 구성:
AI 이미지 프롬프트:

썸네일 C: 감정형
메인 문구:
서브 문구:
이미지 구성:
AI 이미지 프롬프트:
```

## 사실 처리

자극적으로 만들되 사실을 함부로 조작하지 않는다. 모든 내용은 세 축으로 나눈다.

```text
출처축: 기록·사료·백과·논문 등으로 확인되는 내용
해석축: 여러 해석이 가능한 부분
연출축: 이해를 돕기 위해 만든 대사·감정·장면
```

대본 안에서는 확정된 것처럼 말하면 안 되는 부분을 구분한다.

```text
확정 기록, 전승, 야사, 해석, 연출 대사
```

고지문 기본형은 설명란 끝에 넣는다.

```text
※ 본 영상의 인물·배경 장면은 AI로 재구성한 역사 다큐용 연출 이미지입니다.
※ 실존 인물의 실제 초상이나 실제 촬영 영상이 아닙니다.
※ 내레이션에는 AI 합성 음성이 사용되었습니다.
※ 기록이 분명한 부분과 해석이 갈릴 수 있는 부분은 구분해 전달했습니다.
※ 영상 속 일부 대사는 역사적 맥락을 이해시키기 위한 연출용 재구성입니다.
```

## 말투

기본은 짧고 강한 한국어다. 춘식이 사투리는 과하지 않게 10~15%만 쓴다.

좋은 톤:

```text
이건 단순한 질투가 아니었슈.
궁궐에서 권력은 사람을 살리기도 하고, 버리기도 했습니다.
살 수 있었습니다. 그런데 이들은 죽은 왕을 택했습니다.
조선은 그녀를 왕비로 올렸고, 다시 죄인으로 끌어내렸습니다.
```

나쁜 톤: `오늘은 조선시대에 있었던 역사적 사건을 알아보겠습니다.`, `여러분 안녕하세요. 이번 영상에서는...`

## 시리즈 분류

소재는 반드시 아래 시리즈 중 하나로 분류한다.

| 시리즈 | 내용 |
| --- | --- |
| 왕이 선 넘은 날 | 영조, 연산군, 세조, 숙종 |
| 궁궐에서 살아남은 여자들 | 장희빈, 혜경궁 홍씨, 정순왕후, 문정왕후 |
| 죽어서도 벌 받은 사람들 | 부관참시, 능지, 사약, 폐위 |
| 기록에서 지워진 충신들 | 사육신, 고구려 무인, 이름 없는 장수 |
| 조선판 참교육 | 탐관오리 몰락, 권신의 최후 |
| 왕실 가족 비극 | 사도세자, 단종, 폐세자, 왕비 폐위 |

우선순위:

```text
1순위: 왕실 비극

```

## 설명란과 해시태그

설명란은 길게 쓰되, 앞 2줄은 강해야 한다.

```text
{첫 줄: 영상 핵심 사건을 강하게 요약}

{둘째 줄: 이 사건이 왜 중요한지}

이번 영상은 {인물/사건}을 바탕으로 구성한 한국사 쇼츠입니다.
핵심은 {권력/배신/충성/복수/몰락}이 어떻게 한 사람의 운명을 바꿨는지입니다.

출처축:
- {확인 가능한 핵심 기록/사료/백과/인물 정보}

해석축:
- {해석이 갈릴 수 있는 부분}

연출축:
- 영상 속 대사와 일부 감정 표현은 이해를 돕기 위한 재구성입니다.

※ 본 영상의 인물·배경 장면은 AI로 재구성한 역사 다큐용 연출 이미지입니다.
※ 실존 인물의 실제 초상이나 실제 촬영 영상이 아닙니다.
※ 내레이션에는 AI 합성 음성이 사용되었습니다.
※ 기록이 분명한 부분과 해석이 갈릴 수 있는 부분은 구분해 전달했습니다.

#한국사 #역사쇼츠 #조선사 #조선왕조 #궁중비사
```

해시태그는 8~15개만 쓴다. 업로드용 출력은 쉼표 구분 한 줄로 쓴다: `#김만덕, #제주역사, #조선시대, #정조, #한국사쇼츠, #역사쇼츠, #shorts,`. 공백만으로 태그를 나열하지 않는다.


## 썸네일 이미지 프롬프트

AI 이미지 프롬프트는 역사적 분위기를 만들되, 실존 초상처럼 단정하지 않는다.

기본 뼈대:

```text
cinematic Korean Joseon dynasty historical drama scene,
dark royal palace interior,
dramatic red and gold lighting,
a tense royal figure in traditional hanbok,
fear, betrayal, political tragedy,
high contrast, vertical composition,
realistic but stylized historical illustration,
no modern objects, no text, no watermark
```

사건별 감정 예:

```text
사약: noble woman kneeling in a dark palace room, poison bowl, cold royal guards, tragic atmosphere
부관참시: dawn graveyard in Joseon era, soldiers holding torches, covered grave, ominous red sky, no gore
사육신: six loyal scholars in shadow before royal soldiers, refusing to bow, tragic loyalty, palace courtyard
사도세자: lonely wooden rice chest in a dark palace yard, king's shadow, tragic father and son conflict
```

네거티브 프롬프트:

```text
modern clothes, modern buildings, neon signs, guns, cars, text, watermark, logo,
extra fingers, distorted face, gore, blood splatter, cartoon style
```

## 품질 검수

완성 전 반드시 아래를 통과한다.

```text
[제목]
- 감정 단어가 있는가?
- 인물/사건이 명확한가?
- 궁금증이 생기는가?
- 너무 교양 제목 같지 않은가?

[대본]
- 첫 2초에 사건이 터지는가?
- 설명으로 시작하지 않는가?
- 45~58초 안에 끝나는가?
- 확정/해석/연출을 구분했는가?
- 마지막에 역사춘식 한 줄이 있는가?

[썸네일]
- 글자가 18자 이하인가?
- 얼굴/감정/대비가 강한가?
- 제목과 썸네일 문구가 겹치되 완전히 같지는 않은가?
- 밝고 밋밋한 다큐 느낌이 아닌가?

[채널 적합성]
- 역사춘에 맞는 소재인가?
- 시니어/건강/생활정보가 섞이지 않았는가?
- AI 이미지/AI 음성 고지문이 들어갔는가?
```

## 호출 예시

```text
역사춘 스킬로 장희빈 최후 만들어. 제목 10개, 썸네일 3개, 50초 대본, 설명란까지.
역사춘으로 세조와 사육신 쇼츠 하나. 감정 세게, 썸네일은 피빛 궁궐 느낌.
역사춘 기존 영상 리메이크: 수양대군이 문종 앞에서는 하남자였던 이유. 더 자극적인 제목과 썸네일, 45초 대본으로 다시.
역사춘 소재 30개 뽑아. 왕실 비극, 악녀 프레임, 잔혹 형벌 위주로.
```

## 최종 원칙

역사춘 전용 스킬에서는 제목, 썸네일, 대본을 따로 만들지 말고 하나의 패키지로 묶는다. 첫 2초 대사, 상단 제목, 썸네일 문구, 설명란 첫 줄이 같은 감정을 때려야 한다.

```text
역사춘은 역사를 평범하게 설명하지 않는다.
피, 권력, 배신, 충성, 몰락의 감정선을 먼저 세우고,
그 안에 역사 사실을 넣는다.
자극은 제목과 구성에서 만들고,
사실관계는 출처축·해석축·연출축으로 지킨다.
```
