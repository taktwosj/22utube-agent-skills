## 자막

```text
표시 한도    공백 제외 15자 이하 한 줄
cue 시각     타임라인 절대값, 카드 구간 안으로 clamp (시작 올림, 끝 내림)
타이밍       병합해도 원본 cue 경계를 앵커로 재분할한다
             균등 분할만 하면 병합 창 안에서 최대 4초 밀린다 (2026-09-02 실측)
교정 범위    raw / display 양쪽에 똑같이. 한쪽만 고치면 SOURCE_TRANSCRIPT_TEXT_CHANGED
교정 순서    겹침 제거 → 교정. 바꾸면 교정된 단어가 겹침 판정을 깬다
교정표 작성  새 소스를 받으면 vtt_clean 전에 corrections.json 부터 채운다. 회차 고유 인명·
             기관·사건명이 대상이다. 범용 정치 오인식은 vtt_clean.BASE_CORRECTIONS 에 넣어
             다음 회차부터 자동으로 잡히게 한다. 회차 파일에만 넣고 끝내지 않는다
변환 도구    VTT → cues.json 은 vtt_clean.py 로만 한다. 직접 파서를 쓰면 html 엔티티가
             남는다. 자동자막의 화자 전환 표시 `&gt;&gt;` 가 그대로 자막에 박힌 사고가 있었다
             (2026-09-11). vtt_clean 은 html.unescape 와 SPEAKER_MARK 제거를 같이 한다
번인 자막    방송 자막이 박힌 소스는 BURNED_CAPTION 에 넣어 하단 슬롯을 끈다
             ffmpeg 로 프레임을 뽑아 눈으로 확인한 것만 넣는다
```

119의 `validate_srt_text_fidelity` 는 raw/display 가 같으면 통과한다. 양쪽에 같은 오인식이 있으면 못 잡는다. `check_captions.py` 가 그 구멍을 메운다.

### 컷 화제 이탈

한 영상 안에서도 코너가 바뀐다. 사안을 다루다 끝나고 전혀 다른 이야기로 넘어간다.
컷 끝을 나레이션 배분으로 정하면 그 경계를 넘어가 엉뚱한 대목이 화면에 나간다.
2026-09-13 회차에서 공소청 이야기가 끝난 뒤 진행자가 다른 방송 패널을 비판하는
35초가 그대로 실려 나갔다.

`cards_def.TOPIC_RANGE` 에 소스별로 그 사안을 다루는 구간을 적는다. 자막을 읽고
앞뒤 시각을 직접 찍는다. 컷이 이 밖으로 나가면 `SOURCE_CUT_OFF_TOPIC` 으로 실패한다.

```python
TOPIC_RANGE = {
    "Vz38VhGaOD8": (486.0, 1365.0),   # 8:06 ~ 22:45
}
```

자막 내용으로 화제 전환을 자동 판정하려 하지 않는다. 공백·용어 부재·어휘 겹침
셋 다 시험했고 오탐이 검출을 압도한다(27개 중 21개까지 걸렸다). 사람이 구간을
한 번 읽고 적는 쪽이 정확하고 빠르다.

**척추 15분은 이 구간 합으로 센다.** 통짜 길이나 컷 길이 합을 쓰면 사안 밖 발화가
분량에 섞여 미달을 못 본다. 위 회차도 오프토픽 35초를 빼면 14.5분이라 계약 미달이었다.
