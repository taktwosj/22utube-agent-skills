# 작가모드 — 보상앵커: 원본·보상·동행·금지 — 상세

> 원문: `spine-script-119/SKILL.md` 에서 줄 단위로 옮김. 내용 수정 없음.

### 원본과 작가의 자리

원본보다 먼저 답하지 않는다. 작가가 `지역주의를 극복하려고 부산에 출마했습니다` 라고 정리한 뒤 영상을 붙이면 원본은 확인용이 된다. `전국에 이름을 알린 정치인이었습니다. 그런데 다음 선택은 승리와 거리가 멀었습니다` 까지만 쓰고 답은 원본에게 맡긴다. 의미 정리는 원본 뒤에 필요한 만큼만.

원본이 할 수 있는 말은 원본에게 맡긴다. 육성 20초를 작가가 20초 다시 풀지 않는다.

```text
원본 20초 → 작가 5~12초 → 원본 20~40초
```

나레이션 한 줄은 다섯 기능 중 하나다. 어느 것도 아니면 삭제 후보다.

```text
연결   앞 장면과 다음 장면을 잇는다
질문   아직 답하지 않은 것을 남긴다
맥락   원본만으로 알기 어려운 최소 배경
충돌   앞뒤 선택이나 결과의 차이를 짚는다
회수   앞에서 남긴 질문이 어떻게 답됐는지 짧게
```

### 보상 앞뒤 문장

보상 직전에는 결말을 다 말하지 않는다. `그때 가까운 사람이 처음으로 물었습니다` · `투표 하루 전, 선거판을 뒤집는 일이 벌어집니다` 까지다. 보상 직후에는 감정을 강요하지 않고 의미만 잡는다. `이 답은 대통령이 된 뒤 만들어진 회고가 아닙니다` · `여기서 경선의 흐름이 바뀝니다`. 작가가 대신 울거나 분노하지 않는다. 실제 현장과 주변인의 목소리를 먼저 보여준다.

장 전환은 이 꼴이 기본이다.

```text
원본 A
작가 1~2문장
질문 1문장          문구멍
원본 B              보상
작가 1~2문장        의미
다음 질문
```

```text
좋은 보상    다음 원본에서 실제 사람이 답한다 · 결과가 뒤집힌다 · 과거 발언과 나중 행동이 이어진다
            가까운 사람이 뜻밖의 작은 일화를 말한다 · 시청자가 이미 궁금했던 답이 육성으로 나온다
나쁜 보상    작가가 `사실은 이렇습니다` 라고 혼자 설명 · 제목·썸네일에서 이미 공개한 결말
            같은 내용 반복 · 과장한 미스터리를 약한 자료로 회수
```

### 동행 문장

같이 보기 · 멈추기 · 시청자 자리에 앉히기 · 앞에서 들은 것 되짚기 네 가지다.

```text
같이 보기     그 목소리를 우리도 같이 들어 보겠습니다 / 결과를 같이 보겠습니다
멈추기        여기서 잠깐 멈춰 보죠
자리 바꾸기   우리가 참모였어도 똑같이 말렸을 겁니다 / 이런 날 우리라면 무슨 말을 할 수 있었을까요
되짚기        영상 맨 앞에서 우리가 들었던 그 목소리입니다
```

위 문장은 예시다. **그대로 돌려쓰지 않는다.** 직전 회차 원고와 대조해 겹치는 도입·전환 문구를 바꾼다. 같은 기능이라도 어휘와 문형을 갈아 쓴다. 회차마다 같은 문장이 반복되면 시청자가 템플릿을 알아챈다.

실측(동행 표지 줄 수 / 전체 줄): 유시민 09-08 7/135, 이재명 09-13 12/158, 노무현 09-14 29/189. 노무현 회차 수준을 기준으로 삼는다. `check_narration.py` 가 챕터별 수를 찍는다. 표지 단어로 세는 근사치라 0 인 챕터만 경고하고 통과·실패는 가르지 않는다. 사람이 원고를 읽고 판단한다.
