# 시사·정치 롱폼 초벌 집필 프레임

10~20분 정치 비평, 정치인 인물 서사, 복수 원본 클립을 엮는 초벌에 사용하라.
구조 이름은 집필 설계에만 쓰고 완성 대본에 노출하지 마라.

## 구조 선택

| 방식 | 핵심 | 적합한 콘텐츠 |
|---|---|---|
| 기승전결 | 시작→전개→전환→결론 | 일반 스토리텔링 |
| 댄 하먼 8단계 | 결핍→도전→획득→대가→변화 | 인물·감정 서사 |
| PREP | 결론→이유→사례→결론 | 짧고 명확한 정보 전달 |
| 확장 PREP | P·R·E를 분량에 맞춰 반복 | 10~20분 정보성 롱폼 |
| PP-RR-EE-PP | 결론·중요성→복수 이유→복수 사례→결론·행동 | 15분 설득형 롱폼 |
| 두괄식 | 처음부터 핵심 입장 공개 | 뉴스·시사·정보 |
| 미괄식 | 마지막에 핵심 결론 공개 | 이야기·반전형 |
| 감정 미괄식 | 인물 변화를 따라 결론 도달 | 휴먼스토리·감성형 |

시사·뉴스 정치롱폼의 기본값은 다음 조합으로 잡아라.

```text
외부 구조 = 시사·뉴스형 PP-RR-EE-PP
내부 서사 = 핵심 인물의 시련·선택·대가·귀환을 잇는 댄 하먼
장면 연결 = 질문 또는 사실→원본→우리의 판단→다음 장면인 짧은 기승전결
```

순수한 미괄식으로 핵심 입장을 오래 숨기지 마라. 정치 시청자는 초반에
무슨 주장인지 알아야 남는다. 반대로 PREP 이유와 사례를 목록처럼 반복해
보고서로 만들지 마라. 인물의 선택과 대가가 감정을 끌고 가게 하라.

## 15분 기본 골격

- P1: 가장 강한 현재 결론을 첫 문장에 둬라.
- P2: 왜 지금 봐야 하는지, 과거의 어떤 선택이 현재 약속에 무게를 주는지 밝혀라.
- R1: 가장 불리했던 순간의 첫 번째 선택을 보여줘라.
- R2: 그 선택이 말로 끝나지 않고 이어진 행동을 보여줘라.
- E1: 유권자·제도·정치적 결과로 돌아온 사례를 보여줘라.
- E2: 실제 권한을 쥔 뒤의 능력과 추진력을 보여줘라.
- P3: 현재 정국에서 그 기록이 갖는 정치적 의미를 말하라.
- P4: 초반 약속과 과거 선택을 대칭시켜 한 문장으로 회수하라.

R과 E가 더 필요하면 추가하되 같은 뜻을 바꿔 말하며 분량을 늘리지 마라.
각 R은 다른 이유, 각 E는 다른 결과나 능력을 담당하게 하라.

## 인물 내부 서사

인물 정치롱폼의 핵심 구간은 다음 감정 순서를 우선 검토하라.

```text
기존 자리와 욕망
→ 상실 또는 배제
→ 떠날지 남을지 선택
→ 선택을 지키며 버팀
→ 대가를 치름
→ 유권자나 정치적 결과로 보상받음
→ 더 큰 권한을 갖고 돌아옴
→ 과거 선택을 더 큰 현재 약속으로 확장
```

연대기를 전부 설명하지 마라. 현재 결론을 강화하는 선택·대가·결과만 남겨라.

## 정치평론 문체

- 인물 곁에서 현장의 호흡을 같이하는 작가처럼 써라.
- 제3자 검수자가 자료를 분류하듯 쓰지 말고 주어와 행동을 바로 말하라.
- 사용자가 유리한 논평 방향을 정했다면 확인된 사실 위에서 선명하게 평가하라.
- 직접 발언과 기록은 source packet이 의혹·주장·법적 미확정으로 표시하지 않은 한
  불필요한 자기방어 문구를 붙이지 마라.
- 법적 유보가 필요하면 평가 주체를 문장 안에 자연스럽게 귀속하라.
  법률 검토 메모를 따로 읽지 마라.
- 원본이 한 말을 나레이션으로 다시 요약하지 말고 그 선택의 정치적 의미를 말하라.
- 대선 불출마를 가리킬 때는 `차기 대선`으로 통일하라.

완성 대본의 나레이션에서 다음 제작·검수 언어를 사용하지 마라.

```text
이 영상의 범위 / 이 영상 안에서는 / 소스팩 / 자료가 없습니다
검증하겠습니다 / 입증 / 증거로 제시했습니다 / 본인의 주장입니다
단정하지 않겠습니다 / 완결된 평가가 아닙니다 / 확인할 수 있는 것은
공정성이 자동 보장되지는 않습니다 / 함께 따라야 합니다
```

미확정 의혹과 법적 상태를 정확히 표시하는 문장은 금지 대상이 아니다.
다만 그 유보를 모든 자서전적 발언과 정치적 평가에 기계적으로 붙이지 마라.

## 나쁜 문장과 목표 문장

```text
나쁨  선당후사의 증거로 다시 제시했습니다.
목표  다시 선당후사를 외쳤습니다.

나쁨  보도는 두 표현을 함께 쓰며 정확한 범위는 단정하지 않겠습니다.
목표  국회 밖에서도 지역을 지켰고, 마포는 그를 다시 선택했습니다.

나쁨  절차를 제시하는 태도는 강점이지만 공정성이 자동 보장되지는 않습니다.
목표  국회법을 손에 들고 실제 절차를 움직였습니다. 밀어붙일 때는 확실히 밀어붙이는 정치인입니다.

나쁨  이 영상 안에서는 본인의 주장입니다.
목표  반대 근거가 없고 source packet이 미확정으로 표시하지 않았다면 행동과 기록을 직접 서술합니다.
```

목표 문장을 다른 인물에게 복사하지 마라. 같은 원칙으로 해당 인물의 행동과
결과를 새로 써라.

## 정청래 사례의 구조 기준

아래 예시는 해당 source packet이 뒷받침할 때만 사용하라.

```text
P1  정청래가 차기 대선을 내려놓고 민주당 승리의 설계자가 되겠다고 나섰다.
P2  가장 억울한 순간에도 자기 자리보다 당을 택한 기록이 있다.
R1  2016년 컷오프에도 탈당하지 않았다.
R2  당 후보들을 돕고 지역 활동을 이어갔다.
E1  2020년 마포 유권자들이 다시 국회로 돌려보냈다.
E2  법사위원장으로서 국회법을 들고 탄핵 청원과 청문회 절차를 밀어붙였다.
P3  이재명 정부 성공, 총선 승리, 정권 재창출에 자신의 다음을 걸었다.
P4  2016년에는 자기 공천을, 2026년에는 차기 대선을 내려놓고 당의 다음 승리를 택했다.
```

내부 감정선은 `컷오프→잔류→동료 지원→국회 밖 4년→마포 재선택→더 큰
권한→차기 대선보다 당의 승리`로 연결하라.

## 초벌 제출 전 점검

1. 첫 두 나레이션이 결론과 시청 이유를 줬는가.
2. 각 챕터가 다른 질문·이유·사례를 담당하는가.
3. 인물의 가장 큰 대가와 보상이 붙어 있는가.
4. 원본 뒤 나레이션이 원본을 반복하지 않고 우리의 판단을 말하는가.
5. 제작·검수 언어와 방어적 AI 문구가 0건인가.
6. 결말이 첫 문장의 약속을 더 큰 정치적 의미로 회수하는가.
7. 직접인용·법적 상태·사실 확실성은 source packet과 일치하는가.
8. 원본 50~70%, 나레이션 30~50% 목표를 블록 수가 아닌 재생시간으로 다루는가.
