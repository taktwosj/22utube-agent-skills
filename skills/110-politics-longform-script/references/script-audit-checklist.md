# 대본 내용 감사 체크리스트 (P00b)

SHA·cue 수 검사는 무결성일 뿐이다. 이 문서는 **문장 내용**을 본다.
발견은 전부 보고 전용 — 어떤 문구도 임의 수정하지 않는다.

## severity 기준

| severity | 정의 |
|---|---|
| HIGH | 자막으로 그대로 노출되며 시청자가 오류로 인식할 수 있음 |
| MEDIUM | 논지·표기 일관성 훼손. 노출되지만 즉각 오류로 보이진 않음 |
| LOW | 문체·중복. 고치면 좋지만 방송 가능 |

`exposed_as_subtitle` 필드로 화면 노출 여부를 따로 표시한다.

## 검사 항목

### 1. 비문 / 호응 오류
조사·어미가 서술어와 호응하는지. 예: `A보다 … 충돌합니다` — 비교급 `보다`는
`충돌하다`와 호응 불가. 의미상 `A가 아니라`.

### 2. 병렬 어미 불일치
한 문장 안 나열 항목의 어미가 섞였는지. 예: `갖는지 / 배치되는지` 와
`통제할지 / 마무리할지` 혼용.

### 3. 비표준 조어
정치·법률 담론에서 실제로 쓰이지 않는 조합인지. 에피소드 lexicon에 없는 말은
전부 의심한다. 예: `신분 판정`(통용어는 `진영 판정`/`꼬리표`).

### 4. 법률 용어 오류
표준 법률용어인지 확인. 예: `공소 검사`(비표준) → `공소청 검사` 또는 `기소 검사`.
확인 대상 예: `보완수사권` `재수사권` `직접수사권` `수사권` `기소권` `공소청`
`중수청` `국가수사본부` `고위공직자범죄수사처` `형사소송법`.

### 5. 인용 정확성
따옴표 직접인용이 원본 발화와 **글자 단위로** 같은지. 어미만 바뀌어도
인용부호 안에 있으면 위반이다.
예: 원문 `실패로 끝날 거라고 봐요` → 대본 `"그 선택이 실패로 끝날 것"` = 위반.

### 6. 논리 비약 / 지시대상 불명
앞에 등장한 적 없는 비유·지시어가 돌출하는지. 예: 근거 없이 나온 `단순한 예방주사`.

### 7. 무근거 확대
대본이 든 근거가 주장 범위를 실제로 뒷받침하는지. 근거는 A만 말하는데
결론이 A+B로 넓어졌는지 확인한다.

### 8. 인물 표기 불일치
같은 인물이 한 대본 안에서 직함 유지/탈락으로 갈리는지.
나레이션과 메타 필드를 분리해 각각 일관성을 본다.

### 9. 메타 누출
제작용 유보 메모가 화자명·자막 필드에 섞였는지.
예: 화자 필드에 들어간 `진행자 소개 기준 …`. 화면 렌더 대상인지 확인 필요.

### 10. 접속 부사 오용
대비 관계인데 `반대로`를 썼는지(→`반면`) 등.

### 11. 결론 중복
같은 뜻의 마무리 문장이 연속되는지. 111의 `정리하겠습니다` 연속 반복 금지와
같은 계열이다.

### 12. 표기 일관성 통과 확인 (반증 항목)
아래는 통과해도 반드시 기록한다 — 나중에 "검사 안 했다"를 막는다.
- 나레이션 블록 수 / 원본 클립 참조 수 카운트 일치
- 핵심 용어가 나레이션 전 구간에서 동일 표기인지
- 가운데점 표기(`수사·기소`)가 메타 필드와 나레이션에서 어긋나지 않는지
- 주요 인명 지칭 일관성
