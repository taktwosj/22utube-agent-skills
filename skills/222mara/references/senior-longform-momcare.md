| 이유 | 결과는 보여 주고 원인을 비워 확인 욕구를 만든다. | 여러 원인을 거짓으로 하나로 축약하지 않는다. |

## 대본 3구조

### 기승전결

- 기: 상황과 질문
- 승: 배경과 문제 확대
- 전: 새 정보·반전·해결 실마리
- 결: 의미와 행동 방향

영상 전체의 큰 골격으로 사용한다.

### PREP

`Point → Reason → Example → Point`

건강·복지·연금·생활경제·시사처럼 시청자가 답을 먼저 요구하는 정보형에 사용한다. 네 칸의 고정 분량이 아니며 주제에 따라 `P-R1-R2-R3-E1-E2-P`로 확장한다.

권장형:

```text
감정 훅
→ P: 오늘의 핵심 답
→ R1/R2/R3: 이유·조건·예외
→ E1/E2: 실제 사례·수치·원출처
→ P: 요약
→ 오늘 할 행동
```

### 댄 하먼 스토리서클

`일상 → 욕구 → 낯선 상황 → 적응 → 획득 → 대가 → 귀환 → 변화`

관계·외로움·노후 사연·인물 중심 역사에 사용한다. 구체적인 시니어 주인공을 두되, 합성 인물은 실제 인물로 오해되지 않게 표시한다.

### 혼합

1. 오프닝에서 PREP의 P로 약속을 밝힌다.
2. 대표 사례는 댄 하먼으로 몰입시킨다.
3. 제도·건강 근거는 짧은 R-E 블록으로 정리한다.
4. 엔딩에서 마지막 P와 인물의 변화·행동 제안을 합친다.

## 화면·이미지 설계

- 큰 글자, 즉시 이해되는 상징, 한 가지 감정을 우선한다.
- PREP형은 문제 상징 → 이유별 자료화면 → 공식 조건·예외 → 행동 카드로 구성한다.
- 스토리형은 주인공의 나이·외모·옷·장소를 먼저 고정하고 단계마다 표정·행동을 변화시킨다.
- 역사적 사실, 가상 주인공, 재연 장면을 시각적으로 구분한다.
- 얼굴 일관성이 없어도 된다는 강사 답변은 인물 연속 서사에 일반화하지 않는다.
- 강의 화면에서 Genspark 대본 생성은 확인됐지만, 생성된 역사 사실을 사람이 원출처와 대조하는 장면은 확인되지 않았다.

## 사실·출처 검증 게이트

건강·복지·시사·역사에서 다음을 만족하지 않으면 `WAIT_SOURCE_VERIFICATION`이다.

- 중요한 주장마다 원출처 또는 권위 있는 출처가 있다.
- 기준일, 적용 대상, 범위, 예외가 기록돼 있다.
- 인용문과 숫자를 원문과 대조했다.
- 사실, 해석, 경험, 가상 사례, 재연을 분리했다.
- AI 요약이나 인기 영상만으로 사실을 확정하지 않았다.
- 이미지·클립의 사용 권리를 확인했다.

외부 모델은 훅·문장력·논리 비약·반론 누락·시청 지속률 관점의 수정 제안만 한다. 출처, 원본 범위, 확정 타임라인을 임의 변경하지 않는다. 새 근거가 필요하면 `NEEDS_EVIDENCE`로 표시한다.
