# Politics Narration / Dialogue Prompt (111-politics-longform / G20)

> 외부 나레이션·대사 작성용 Prompt. `politics_narration_framework.md`의
> 빈 칸(나레이션 자리)만 작성한다. 사용자가 수동으로 전달·회수한다.

## 목적

```text
정치롱폼의 챕터 구조와 원문 인용을 유지한 채
지정된 나레이션 자리만 작성한다.
```

## 입력 구조 (framework)

```text
영상 목적
정치적 문제의식
대상 시청자와 문체
인트로 자리
인삿말 자리
챕터 제목
챕터 질문
원문 자동자막 전문 또는 선택 구간
출처·게시일·원본 시간
확인된 사실
발언자의 주장·추론
외부 나레이션 작성 자리  ← 이 자리만 작성
사용할 영상·SRT 계획
챕터 맺음말
다음 챕터 연결 질문
최종 결론의 역할
출처 목록
```

## 챕터 제목 규칙

```text
CHAPTER 3 (X)  — 의미 없는 제목 금지
CHAPTER 3
검찰개혁은 대통령 뜻 때문에 멈췄나 (O)
```

## 나레이션 품질

정치 나레이션은 단순 동기 부여나 감정 단정이 아니라 논리의 연결을 설명한다.

```text
무슨 발언·행동을 판단하는지
어떤 사실·역사적 맥락이 있는지
그 사실에서 어떤 논리로 판단에 도달하는지
사실·발언자 해석·제작자의 판단이 각각 무엇인지
```

## 출력 요청

```text
지정된 나레이션 자리만 작성하십시오.
챕터 구조와 원문 인용을 변경하지 마십시오.
AI식 일반론과 반복 표현을 피하십시오.
행동과 판단의 이유·맥락을 설명하십시오.
인물·기관 이름의 오타를 확인하십시오.
의심되는 자동자막을 표시하십시오.
논리적으로 연결되지 않는 문장을 표시하십시오.
추가 근거가 필요한 주장은 NEEDS_EVIDENCE로 표시하십시오.
```

## 보조 태그

```text
POSSIBLE_NAME_ERROR
POSSIBLE_SUBTITLE_ERROR
LOGIC_CHECK
NEEDS_EVIDENCE
```
