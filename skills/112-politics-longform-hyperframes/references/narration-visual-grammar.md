## 적용 경계

나레이션 장면은 승인 대본과 production design의 의미만 시각화한다. 새로운 사실이나
문장을 추가하지 않는다. 딥 네이비, 청록색, 흰색, 금색의 방송 정치 다큐 톤은
유지한다. 사각형 카드와 직선 화살표의 반복을 줄이고 내용에 맞는 구조 하나를 고른다.

도형은 episode CSS와 inline SVG로 만든다. 기존 이미지 크롭은 사용할 수 있다.
외부 이미지 생성은 기본 공정에서 제외한다. 인물 누끼는 승인된 히어로 시안과 같은
원본 중심 장면에 한해 기존 소스나 사용자 제공 자산으로 허용한다.

## 자동 선택

다음 순서로 문법을 선택한다.

```text
시간 순서                     TIMELINE_PATH
원인, 선택, 행동, 결과        FLOW_NODES
중심 목표와 3개 또는 4개 요소 CORE_ORBIT
두 가치 또는 두 선택 비교     COMPARE_SPLIT
단계적 변화 또는 강화         STEP_PROGRESS
핵심 발언, 결론, 장 전환       QUOTE_SPOTLIGHT
```

판단 우선순위는 실제 대본 의미, 챕터 역할, 직전 장면과 다른 구성, 화면 여백,
장식 효과 순이다. 선택이 불분명하다는 이유로 `QUOTE_SPOTLIGHT`를 자동 기본값으로
쓰지 않는다.

## 여섯 가지 문법

### FLOW_NODES

원인에서 결과까지의 인과를 최대 4개 노드로 표현한다. 시작은 원형, 선택은 마름모,
행동은 둥근 캡슐, 결과는 이중 원이나 강조 링을 사용한다. 시작 노드, 연결선,
다음 노드, 결과 강조 순으로 한 번만 진행한다.

### TIMELINE_PATH

사건의 시간 순서와 과거에서 현재로의 연결을 완만한 곡선 경로로 표현한다. 연도는
원형 마커 안이나 위에 두고 설명은 바로 아래에 짧게 둔다. 현재 시점만 금색 링,
이전 시점은 회청색, 최종 시점은 청록색 또는 흰색으로 표시한다. 큰 연도 숫자는
배경에 4퍼센트에서 7퍼센트 불투명도로만 사용한다.

### CORE_ORBIT

핵심 목표 하나와 주변 요소 3개 또는 4개를 연결한다. 중앙은 큰 원 또는 육각형,
주변은 작은 원이나 캡슐 또는 방패형을 사용한다. 중앙 문장은 2줄 이하, 주변 문구는
각각 6자에서 12자로 제한한다. 중앙을 먼저 보이고 주변 요소와 연결선을 순서대로
완성한다. 회전 애니메이션은 사용하지 않는다.

### COMPARE_SPLIT

두 가치나 선택을 같은 크기의 좌우 영역으로 비교한다. 반원이나 세로 캡슐을 사용하고
중앙에는 가는 구분선, 저울, 양방향 화살표 또는 전환 화살표 중 하나만 둔다.
선택된 방향만 금색 또는 청록색으로 한 번 강조한다. 반대편을 악역처럼 과도하게
어둡게 만들지 않는다. 각 비교 문장은 최대 2줄이다.

### STEP_PROGRESS

강화되는 과정을 최대 4단계 계단이나 셰브론으로 표현한다. 아래 단계부터 순서대로
등장시키고 최종 단계만 밝기와 테두리로 강조한다. 단계마다 크기를 무조건 키우거나
계단 높이를 과장하지 않는다.

### QUOTE_SPOTLIGHT

핵심 발언, 챕터 결론, 다음 장 연결 문장을 집중시킨다. 큰 인용부호는 배경에
6퍼센트에서 10퍼센트 불투명도로만 두고 본문을 가리지 않는다. 핵심 문장과 짧은
강조선, 한 줄 설명만 사용한다. 문자별 등장, 타자기 효과 남용, 전체 금색 처리,
강한 흔들림은 금지한다.

## 반복 방지

```text
같은 문법 연속 사용             금지
전체 6개 챕터의 최소 문법 수    4종
한 챕터의 최대 문법 수          2종
한 화면의 주요 도형 수          최대 5개
한 화면의 강조색 수             청록색과 금색 2종
모든 문장을 도형 안에 넣기      금지
```

도형은 핵심 개념만 담고 설명 문장은 별도 영역에 둔다. 아이콘, 선, 도형을 한 화면에
동시에 과다 사용하지 않는다. 화면마다 장식을 늘리는 것이 아니라 내용에 맞는 구조
하나를 선택해 다양성을 만든다.

## 모션과 SRT 동기화

실제 보이스 길이를 측정하고 확정된 SRT 발화 구간에 맞춰 등장시킨다. 임의의 고정
초 단위만으로 배치하지 않는다.

```text
핵심 구절 시작   관련 도형 등장
설명 구절 시작   연결선 또는 보조 노드 등장
결론 구절 시작   최종 노드 또는 핵심 문장 강조
```

권장 범위는 텍스트 0.32초에서 0.45초, 도형 0.35초에서 0.50초, 연결선 0.45초에서
0.70초, 요소 간 지연 0.08초에서 0.16초, 장면 종료 페이드 0.20초에서 0.35초다.
opacity, 짧은 이동, 0.97에서 1까지의 scale, SVG line draw, 강조선 확장, 한 번의
약한 halo만 사용한다. bounce, 과도한 zoom, 반복 회전, 무한 pulse, 빠른 깜박임,
파티클, 3D 카드 회전, 네온 테두리, 화면 전체 흔들림은 금지한다.

## 원본 영상 장면

원본 영상은 나레이션 그래픽과 분리한다. 영상 크기와 위치, 하단 자막을 유지하고
출처와 날짜는 좌측 상단, 화자 구분은 헤더 또는 영상 우측 상단, CTA는 상단 우측에
둔다. 영상 위에 흐름도나 장식 도형을 덮지 않는다. 실제 발언과 표정을
정보 장식보다 우선한다.

```text
내부 source ID 노출 0건
한 화면 주요 도형 5개 이하
승인 대본 밖 문구 추가 0건

승인되지 않은 외부 이미지 생성 0건
```
