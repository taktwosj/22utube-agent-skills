# 승인 시각 기준 프레임

## 권위

사용자가 제공한 네 장의 시안을 정치롱폼 HyperFrames 화면의 최우선 시각 기준으로
사용한다. 색상, 여백, 타이포그래피 위계, 정보 밀도, 테두리 강도는 이 프레임을
따른다. 문구와 인물은 에피소드 승인 대본과 실제 소스로 교체한다.

정확한 파일과 SHA-256은
`../assets/political-documentary-reference-frames.json`을 기준으로 확인한다.

## 프레임 유형

### SOURCE_QUOTE_HERO

참조 이미지: `../assets/reference-frames/source-quote-hero.png`

- 딥 네이비 배경에 인물을 중앙보다 오른쪽에 크게 배치한다.
- 좌측 상단에는 챕터 번호, 제목, 실제 채널명, 업로드 날짜를 둔다.
- 우측 상단에는 채널 표기와 작은 CTA를 둔다.
- 하단에는 화면 폭의 약 85퍼센트인 얇은 테두리 인용 패널을 둔다.
- 큰 인용부호는 청록색, 본문은 흰색으로 처리한다.
- 인물 누끼는 기존 소스나 사용자 제공 자산으로 확보된 경우 허용한다.

### NARRATION_SUMMARY_SPLIT

참조 이미지: `../assets/reference-frames/narration-summary-split.png`

- 상단은 챕터 번호, 중앙 제목, 우측 CTA의 한 줄 헤더다.
- 좌측 25퍼센트 전후에는 여섯 개 챕터 목록을 둔다.
- 활성 챕터만 금색 세로선과 번호, 흰색 제목으로 강조한다.
- 우측은 핵심 판단, 설명, 두 항목 전환, 보조 시간 목록을 한 화면에 정렬한다.
- 사각형은 모든 문장을 감싸는 용도가 아니라 선택과 결과를 묶는 용도로만 사용한다.

### NARRATION_PROCESS_CIRCLES

참조 이미지: `../assets/reference-frames/narration-step-circles.png`

- 좌측 챕터 목록과 상단 헤더는 동일한 위치를 유지한다.
- 우측 본문에는 최대 네 개의 원형 단계와 단방향 연결선을 사용한다.
- 원형은 파랑, 청록, 초록, 금색 순으로 진행을 보여줄 수 있다.
- 아이콘과 약한 광택은 허용하지만 반복 점멸과 강한 네온은 금지한다.
- 각 원 아래에는 한 줄 또는 두 줄의 설명을 두고 하단에는 결론 패널을 둔다.

### CTA_END_CARD

참조 이미지: `../assets/reference-frames/cta-end-card.png`

- 마지막에 한 번만 사용하는 독립 화면이다.
- 중앙에는 작은 청록색 말풍선 아이콘과 고정 CTA 두 줄을 둔다.
- 하단에는 낮은 밝기의 청색 곡선 그리드나 파동을 사용할 수 있다.
- 챕터 목록, 출처, 제목, 인물은 표시하지 않는다.
- 이 화면의 CTA는 챕터 헤더의 작은 CTA를 대체하지 않는다.

## 공통 판정

```text
딥 네이비 배경 유지
흰색 본문과 청록색 연결 강조
금색은 활성 선택과 최종 결과에 제한
굵은 고딕 중심의 명확한 제목 위계
얇고 낮은 대비의 패널 테두리
좌측 챕터 목록 위치 고정
우측 하단 CTA 0건
게임 HUD와 과도한 네온 0건
```

시안과 구현이 충돌하면 장식 세부보다 레이아웃, 위계, 여백, 가독성을 우선한다.
