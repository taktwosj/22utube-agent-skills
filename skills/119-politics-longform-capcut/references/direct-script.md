# 직접 대본

PRE-119 강한 표식 하나 또는 보조 표식 두 개 이상이 전혀 없고 승인된 대본도 없을 때만
이 문서를 읽는다. 119 안에서 초안을 만들며 110·111을 호출하거나 그 산출물을 요구하지
않는다. PRE-119 표식이 있으면 승인 대기 중이어도 direct-script로 우회하지 않는다.

## 최소 입력

`episode_id`, 주제, 핵심 방향, 출처 URL·원본 SRT·로컬 미디어 중 하나 이상, 목표 길이를
받는다. 출처가 없으면 사실 단정이나 직접 인용을 만들지 말고 필요한 출처를 요청한다.

## 작성 구조

```text
M-PP-RR-EE-PP
M  오프닝 몽타주 0:00~0:45
P1 가장 강한 현재 결론
P2 지금 봐야 할 이유
R1 첫 이유 또는 선택
R2 이어지는 행동 또는 둘째 이유
E1 실제 결과 또는 사례
E2 권한을 얻은 뒤의 능력
P3 현재 정치적 의미
P4 결론에서 오프닝 약속 회수
```

M은 본편에서 가장 센 발화 5~7개를 6~10초씩 잘라 세기 순서로 붙인 구간이다. 나레이션과
해설을 얹지 않고 원본 발화만 쓰며, 끝에 3초 CTA를 붙이고 P1로 진입한다. 몽타주에 쓴
구간은 본편에서 다시 나온다. 후킹은 세기로 고르며, 적대 진영 비판은 결론이 예측되므로
아군 내부의 이탈·경고 발화보다 약하다.

내부 전개는 `기존 자리·욕망 → 상실·배제 → 선택 → 인내 → 비용 → 정치적 보상 → 더 큰
권한을 얻어 귀환`으로 잡는다. 장면은 `질문 또는 사실 → 출처 영상 → 우리의 정치적 판단
→ 다음 장면`으로 연결한다.

리텐션 편집은 오프닝 훅, 챕터 순서, 정보 공개 시점, 출처·나레이션 배치, 반론·법적
유의점, 반복 삭제, 결말 회수를 다시 쓰는 일이다. 실제 데이터가 없으면 약 45~75초마다
새 증거·반론·결과를 배치하되 validator gate로 만들지 않는다.

## 외부 의견과 승인

대본 초안 단계에서만 독립 외부 의견을 병렬로 수집해 조언으로 반영한다. 제공된 출처 밖의
사실을 만들지 않고, 직접 인용을 바꾸지 않으며, 의혹을 사실로 단정하지 않는다.

외부 의견은 영수증·lock·review packet·승인 조건이 아니다. 사용자에게 최종 대본 하나를
제시한다. 승인 전은 `WAIT_SCRIPT_APPROVAL`, 승인 뒤는 `DIRECT_SCRIPT_READY`다. 승인 뒤에는
외부 의견이나 대본 승인을 다시 요구하지 말고 A–D 제작을 시작한다.
