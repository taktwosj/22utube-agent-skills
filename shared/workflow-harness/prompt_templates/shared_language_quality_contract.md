# Shared Language Quality Contract (V2)

> 이 계약은 모든 외부 AI용 Prompt packet에 공통으로 append된다.
> Gemini / 외부 결과는 선택 입력이며, 원본 영상과 로컬 분석이 1차 권위다.

## 금지

```text
기계적 백과사전 문체
같은 단어·문장 시작 반복
감정을 단순 명사로만 표현
근거 없는 인물의 속마음 단정
뜻이 불분명한 과도한 축약어
모든 문단을 교훈으로 끝내는 AI식 결론
보이는 장면을 아무 의미 없이 그대로 반복
```

## 피해야 할 예

```text
무서운 다람쥐
기쁜 사람
슬픈 여자
그는 화가 났다
이것은 중요한 문제다
모터 달람쥐
```

## 권장 방향

```text
몸을 잔뜩 웅크린 채 벌벌 떤다
입꼬리가 올라가더니 결국 웃음을 터뜨린다
한동안 말을 잇지 못하고 숨을 고른다
기쁜 마음을 감추지 못한 채 몇 번이고 손을 흔든다
```

## 쇼츠 언어 (general_shorts_design 전용)

```text
짧지만 뜻을 훼손하지 않는다
장면이 바로 떠오르는 동사 사용
중복 단어 최소화
웃긴 장면은 리듬과 감정을 살린다
슬픈 장면은 사실보다 과장하지 않되 감정의 움직임을 구체화한다
영상에 없는 행동은 만들지 않는다
```

## 정치롱폼 언어 (politics_longform 전용)

정치 나레이션은 단순 동기 부여나 감정 단정이 아니라 논리의 연결을 설명한다.

```text
무슨 발언·행동을 판단하는지
어떤 사실·역사적 맥락이 있는지
그 사실에서 어떤 논리로 판단에 도달하는지
사실·발언자 해석·제작자의 판단이 각각 무엇인지
```

나쁜 형태:

```text
유시민이 이재명을 비판한 것은 아꼈기 때문이다.
```

권장 형태의 구조:

```text
비판의 초점은 개인 감정이 아니라,
과거 검찰 권력의 위험을 지적해 온 인물이
지금 같은 구조와 타협하는 듯 보인다는 데 있다.
```

위 문장은 사실 확정문이 아니라 문장 구조 예시다.
